# 损伤评估页面与交互式合成演示

## 当前演示（2026-09-11：局部连续云图）

原“查看演示”入口与 /damage_assessment_demo.html 已改为三层建筑和地面的交互式合成场景。原住宅静态网格及报告文件保留为历史资料，不再作为默认演示。

操作：进入“损伤评估 → 查看演示”，编辑爆源 X/Y/高度/当量，添加或移除爆源，点击“开始评估”。修改任何输入即清空旧等级、颜色、报告链接；再次评估后同步更新。支持隐藏外墙、点击模型或明细行查看构件依据、恢复默认设置。离开演示不改动真实项目与浏览器持久状态。

演示输入边界为 1—5 个源、X/Y ±15 m、高度 0—15 m、当量 1—1000 kg，仅为输入/资源界限，不代表物理适用范围。合成响应映射没有爆炸经验公式或当量物理换算，不用于实际爆源设计。多个源只驱动可重复的演示样本，不模拟实际波传播、遮挡或载荷叠加。

| 功能 | 当前覆盖方式 |
| --- | --- |
| 建筑、地面与整体评估 | 小型合成时序通过现有公开 assess API 和原规则计算 |
| 模型局部分布 | 柱、梁、墙、板和地面表面细分采样，使用固定 0—1 无量纲合成影响值连续着色；未评估、过期、不可评估为灰色 |
| 构件整体等级 | 右侧保留原评估引擎的 0—4 离散等级与判定依据，不把局部显示值当作局部损伤等级 |
| 模型交互 | 旋转、缩放、适配、外墙隐藏、模型点击与明细行选择 |
| 可评估性门禁 | complete、partial（地面身份不可核验）、blocked（缺位移） |
| 指标与依据 | 构件相对变形、连接区域、地面几何/尾段稳定性、规则命中和限制 |
| 报告 | 查看/下载带合成标记的 HTML，建筑和地面 CSV |
| 快照、规则、证据与完整性 | 页面规则查看；JSON 包含八项原始工件及 SHA256；显示前校验工件 |
| 失败和过期 | 参数修改撤销旧结论；503、错误响应或哈希不符不保留旧报告 |
| 真实项目隔离 | 专用演示路由、不接受项目 ID/路径、不登记真实求解完成、不启动求解 |

地面四区用于定位，模型表面显示局部合成影响分布；右侧四区仍引用同一地面整体等级，不声称四区独立定级。详细区域指标由原评估引擎输出，径向参考为第一个源。模型展示原始示意几何，不构造裂缝、倒塌或求解后变形。

局部云图使用独立的前端合成显示场 `synthetic_surface_field@1`，不是将构件整体等级做渐变，也不是从求解位移、压力、冲量或材料损伤量推导的局部响应。它只用于展示参数变化、局部峰值和连续着色的交互，固定标尺不做逐帧最大值归一化。源位置/高度移动局部峰值；当量/数量只影响任意合成包络，不涉及物理换算或真实叠加。柱中部较强仅在相应演示源设置下出现，不预设所有柱都中间最重。

只有当前评估成功且对象门禁允许时才生成其局部显示值；缺失对象没有值且保持灰色。细分仅改变演示表面采样，不改动求解网格、真实评估算法或输入文件。构件详情同时显示局部影响值范围与整体等级，并明确两者不同。

完整证据包保留八项原始评估工件及原 SHA256，另附 `display_field` 的版本、评估 ID、输入、表面坐标/连接和采样值。该附加显示场不属于原始评估工件的哈希覆盖范围，也不参与原规则定级；HTML 展示报告有同样的区别说明。

“完整”指本演示所需的数据完整，不是所有材料历史变量齐全。示意弹性材料无法提供塑性损伤量，系统如实提示缺失，不填零。原始工件和其哈希保留在完整证据 JSON 中；HTML/CSV 是额外标记的展示副本，不能用原工件哈希校验展示副本。

用户已批准的未覆盖项：真实 d3plot 解析链路验证、正式工程鉴定。所有结果均为合成数据演示和研究参考，不能用于工程结论。

安装仍使用主项目可选评估依赖。演示计算在唯一系统临时目录内进行，完成后清理自身临时输入和输出；下载的证据包不依赖该临时目录。

## 使用

启动本地 Web 服务，访问 `/refined-building-blast`，点击底部“损伤评估”→“查看演示”。也可以直接打开 `/damage_assessment_demo.html` 查看同样内容；“退出演示”位于工作台外层，独立页面没有该按钮。

演示以独立 iframe 和独立三维查看器显示，不替换真实项目的 store、草稿、生成包身份或模型查看器。关闭演示移除 iframe，恢复原评估面板。演示只请求静态资源，真实评估仍走原受控接口，不引入 DeepSeek。

## 重新打包

在仓库根目录运行下列命令。输入必须是同一住宅案例的原模型目录及评估产物目录；打包工具校验模型、语义和评估身份，拒绝错配；不执行求解或评估。

```powershell
python -m tools.build_damage_assessment_demo --reference <原模型目录> --assessment <评估产物目录> --output lsprepost_mcp/web/static/demos
```

兼容此案例混用的逗号和 8 列定宽实体记录，只在打包输入中标准化，不改动原始模型或主项目通用解析器。生成文件随页面分发，运行时不依赖原大体积 d3plot 文件和可选 lasso 包。
