# Phase 18 三类精细建筑 Solver-Complete ALE/FSI 验收报告

日期：2026-08-21

## 结论

Phase 18 已新增一条独立的 `solver_complete_ale_fsi` 生成与验证路径，并对商业超市、住宅建筑和地铁入口三类真实资产完成以下闭环：

1. 按构件物理特征选择 Solid、Shell 或 Beam，不把建筑外壳整体填成单一实体，也不禁止合理的混合单元族；
2. 生成包围建筑、地面和 TNT 的可见 MM-ALE 空气域；
3. TNT 当量和三维位置可配置，默认当量 2 kg、位置 `(-2.0, 1.5, 4.0) m`；
4. 写出依赖闭合的单体 `model.k`，包含 TNT、空气 EOS、体积分数初始化、起爆、非反射边界、地面、建筑和真实 FSI；
5. 三包均通过真实 LS-PrePost 导入、LS-DYNA R12 `mcheck=y` 和串行 1 ms 验证求解；
6. 三次求解均正常终止，达到目标时间，能量有限且稳定，并检测到 TNT 起爆后空气压力先于建筑响应到达。

本轮结论是“求解型工作流与 1 ms 初始传播验收通过”，不是“工程爆炸响应标定完成”。所有产物继续保持：

- `solver_ready=false`
- `requires_project_review=true`
- `engineering_validated=false`

机器本地证据位于 `<MODEL_OUTPUT_ROOT>\Phase18_三类精细建筑_ALEFSI_20260820`。实际机器路径不写入可分发报告；根目录中的 `solver_blast_summary.json`、`lsprepost_import_summary.json` 和 `solver_blast_r12_summary.json` 是机器可读权威汇总。

## 建筑物理建模审查

三类建筑均通过构件连接审计，`audit_findings=[]`，基础—竖向构件—楼板/屋盖承重路径均为 `continuous=true`。

### 商业超市

- 承重路径：`hybrid_foundation` → `steel_column`/入口钢柱 → `hybrid_slab`/`steel_beam`/`steel_roof_deck`。
- Solid：混凝土基础、楼板和带真实门洞的砌体/预制实体围护。
- Beam：承重钢柱、钢梁、入口门框和钢筋。
- Shell：钢屋面板与非承重隔墙。
- 入口门洞由钢门框承重构件闭合，未用空气或外壳假装承重柱。

### 住宅建筑

- 承重路径：`rc_foundation` → `rc_column`/`rc_shear_wall` → `rc_slab`/双向 RC 梁。
- Solid：RC 基础、柱、梁、剪力墙、楼板和实体外墙。
- Beam：纵筋、箍筋、墙筋、板筋和基础钢筋。
- Shell：阳台栏板和非承重隔墙。
- 空层只来自明确楼层、洞口或非承重空间；未用缺失实体模拟楼层。

### 地铁入口

- 承重路径：`rc_box_floor` → `rc_box_wall`/`pavilion_frame` → `rc_box_roof`/上平台/金属屋面。
- Solid：地下 RC 箱体地板、墙、顶板、楼梯、平台和入口基座。
- Beam：入口钢框架、楼梯/墙/板钢筋、扶手和扶梯导轨。
- Shell：入口玻璃、金属屋面、扶梯踏步带和玻璃栏板。
- 地面由独立土体 Solid 表示；建筑—地面接触和地面—空气 FSI 均进入清单。
- 埋置基座及默认外部爆炸场景下受围护遮蔽的内部楼梯/平台/扶梯构件，不直接发布为外部空气 FSI 面；外部 RC 箱体、玻璃和金属屋面继续耦合。

这里的“混合单元族”是按物理对象分工，不是同一构件角色混用多种单元。代码会在同一角色同时出现 Solid/Shell/Beam 时直接拒绝。

## 找到并修复的生成链路问题

1. R12 固定宽度数值字段对小数前导零敏感；写出器改为 R12 可接受的受限表示。
2. 初始 FSI 四点积分和 `*DATABASE_ALE` 组合会在 R12 中产生不稳定/终止；改用经实际 R12 验证的单点耦合，并保留必要 ALE 材料/历史输出。
3. 插值卡包含零权重节点会制造无效或不闭合约束；现在只写正权重并验证权重和为 1。
4. 结果解析器曾把 R12 说明文字中的 “NaN check” 和 “nanoseconds” 误判为数值 NaN；现在只拒绝数值位置的 NaN/Inf，并要求权威 `glstat` 能量。
5. 住宅和地铁的 RC/玻璃/钢屋面/扶梯材料角色曾错误落入非承重材料；现在使用闭合角色映射并逐角色测试。
6. 地铁入口埋置基座及内部楼梯/扶梯构件曾被错误直接发布为外部空气 FSI，导致基座负体积；修复外部暴露分类后，地铁从约 0.15 ms 错误终止变为 1.0004 ms 正常终止。
7. 爆源默认位置从靠近边界/构件的旧值调整为 `(-2.0, 1.5, 4.0) m`，并保持用户可修改。

旧失败运行和诊断模型均保留在机器本地故障档案中，没有手工修改最终 K 文件；正式三包全部由修复后的同一生成链路重新生成。
