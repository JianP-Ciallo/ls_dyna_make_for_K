# Phase 18A–C 对抗性审核修复报告

日期：2026-08-09
状态：两轮软件级修复与最终复审修复已形成可复现提交；工程级验证仍待项目审核。

## 1. 审核范围与结论

本轮以真实调用者和异常输入为测试对象，审核 Phase 18A 的源文件拆解与构件资源、Phase 18B 的材料/结构资源审核闭包，以及 Phase 18C 的精细化建筑内核。修复仅位于资源审核和 `lsprepost_mcp/refined_building/` 独立内核，没有引入其他场景生成模块。

Phase 18A 未复现新的拆解缺陷：源文件身份、流式解析、构件级独立载荷、命名别名、坐标变换、ID 命名空间、确定性导出和精确重组测试均保持通过。第一轮在 Phase 18B/18C 复现并修复八类软件正确性缺陷；第二轮对抗测试又复现十类语义、边界与输出闭包缺陷。两轮共修复十八类缺陷。

## 2. 已修复问题

### 2.1 第一轮审核修复

1. **审核提升未完全 fail-closed**：过去 `apply_effective_review` 只核对资源哈希和状态，错误的清单版本、源哈希、审核日期、方法、证据或资源类型仍可能获得有效审核状态。现已抽取统一审核记录校验器，完整清单校验与运行时提升共用同一规则，材料和结构资源调用者分别锁定 `material`、`structural` 类型。
2. **结构闭包只检查材料 ID**：过去负密度等非法材料对象只要键名存在即可通过。现在规范化并比对字典键与对象 ID，拒绝重复身份，并对每个实际引用的材料调用类型化材料校验。
3. **空间未受所属楼层约束**：空间现在除建筑包络外，还必须完整位于其 `level_id` 对应的高程区间。
4. **开口拓扑与实体位置脱节**：开口必须接触声明的每个空间；连接 `exterior` 时还必须接触建筑包络。同一对空间允许存在多扇门，邻接图保持去重，而实体开口记录全部保留。
5. **梁柱板墙独立网格造成重叠与断裂**：新增确定性轴对齐并集网格器。构件边界、目标网格尺寸和空洞边界共同形成全局轴；每个占用网格单元只生成一次，并按稳定优先级确定 Part 角色；所有交汇构件共享同一坐标节点。
6. **浮点近重复轴产生极薄单元**：全局轴会在 `1e-12 m` 容差内归并数值近等坐标，避免剪力墙体系出现退化表面。
7. **钢筋仅按线段中点过滤空洞**：改为有限线段与收缩 AABB 内部的 slab 相交测试。偏心门洞回归中原有 7 个穿洞钢筋段已归零，边界贴合但不进入内部的钢筋仍保留；验证器也独立检查该不变量。
8. **结构 Shell 未发布为可选表面**：钢结构 Shell 现在生成 `shell:<element_id>` 表面记录，包含节点、Part、质心和法向，并进入与 Solid 一致且互斥的外表面/内表面/地面/未分类目录。默认钢框架 4 个屋面 Shell 均为外表面且用户可选；与 Solid 边界重合的混合结构 Shell 不重复发布，避免后续载荷重复选择。

新增验证门禁还会报告：Solid 使用节点的重复空间坐标，以及 `rc_frame`、`rc_frame_shear_wall`、`rc_box` 混凝土 Solid 的非单一连通分量。

### 2.2 第二轮统一语义加固

9. **房间空间误删合法梁柱与钢筋**：`spaces` 现在只描述房间/空气拓扑，不再作为 RC 构件或钢筋切除体；当前只有显式 `openings` 切除结构。默认 3×3 轴网恢复为 9 根柱、X/Y 方向各 6 段梁，中心轴网柱合法保留。
10. **多层 RC 柱脚规则造成楼层断开**：最低层基础顶与柱底共享坐标面；其余楼层柱从本层 `elevation_m` 起步并与下层楼板共享节点。两层 RC 混凝土保持一个共享节点连通分量；非零最低层标高也有回归覆盖。
11. **空白审核证据被接受**：`evidence` 每项必须在 `strip()` 后仍非空，纯空白字符串 fail-closed。
12. **审核映射键与对象身份可脱钩**：资源映射键、对象 `id` 和审核记录 `id` 必须一致，且仍须通过同一对象的规范哈希校验。
13. **结构 Set 身份可重复**：以 `(set_type, source_id)` 作为 Set 规范身份，完全重复时拒绝。
14. **耦合关系身份可重复**：同时保证 `coupling_index` 唯一，以及 `(slave_kind, ssid, master_kind, msid, sstyp, mstyp)` 完整关系签名唯一。
15. **极端尺寸可生成建筑包络外网格**：RC 使用实际梁底 `level_top - slab_thickness - beam_depth` 做预网格校验，声明剪力墙必须位于包络内；混合结构基础/楼板厚度分别受包络和所属楼层高度约束。验证器另从 Solid/Shell/Beam connectivity 收集结构节点，报告 `structural_node_outside_envelope`，但不误报未被结构单元引用的孤立节点。
16. **部分暴露 Shell 被质心近似错误抑制**：轴对齐 Shell 仅在同平面轴对齐 Solid 面的二维矩形并集完整覆盖时去重。部分覆盖保留；旋转 Shell 或旋转 Solid 候选面只能通过前置 exact face-key 去重；相邻、重叠及极窄正面积覆盖条带均有回归测试。
17. **正体积重叠 opening 被接受**：合同规范化阶段拒绝任意三轴均有正长度交集的 opening；仅边界接触仍合法，同一空间对可保留多个互不重叠开口。
18. **开口过滤后残留孤立钢筋节点**：仅保留仍被 Beam 引用的节点，并按旧 ID 排序稳定重编号；Beam element ID、角色、顺序和存活角色的 `part_bindings` 保持兼容。

三项任务均经过独立规格/代码质量审查。Task 2 和 Task 3 各执行一轮修复复审。最终整体验收随后又发现三项交付级问题：RC 箱体仍把 `spaces` 用作结构切除体、同一空间对多开口修复尚未进入受审版本、以及 Phase 18A–C 的若干生产依赖与资源包只存在于混合工作树。最终修复波次已统一关闭三项问题：RC 箱体混凝土和钢筋现在只接受 `opening_regions` 作为切除体；多开口经 `compile_spatial_topology` 端到端保留且邻接集合去重；全部必需代码、材料、结构资源、完整模型与四个构件包已纳入提交 `4ac51b9`。

最终修复没有纳入当前工作树中与本阶段无关的城市、Phase 16B、Web 或 `server.py` 改动；`schema.py` 也只提交了 `model_resources` 相关片段。构件包仍可通过公共模型生成链附加到旧有模型类型，并可通过 `model_library.export_model_resource` 独立导出 K 文件。
