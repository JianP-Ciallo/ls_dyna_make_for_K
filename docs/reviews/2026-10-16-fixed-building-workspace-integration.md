# 固定建筑工作区限定集成

用户已确认三维预览效果，授权合入主工作区并要求保留独立入口。主导航新增“固定建筑压力分析”，通过 `/fixed-building-pressure` 查看建筑，通过 `/structural-pressure` 配置用户提供的压力时程并导出结构 K 文件包。

新页面支持整栋旋转、缩放、楼层内部剖切、俯视平面、正立面、房间尺寸和显示开关。它与压力导出共用登记结构模板，包含 831 个构件、66 个空间和 3 m 混凝土地面。显示调整不修改结构网格。

## 合并边界

- 从当前主分支 HEAD 单独建立集成提交，仅引入审核过的固定建筑资源、压力模块、页面和专项测试；不整分支合入架构实验。
- 已有 `web/app.py` 只增加独立服务生命周期及专属 API/静态路由，`static/index.html` 只增加入口及限定样式。原精细化爆炸页面、API 模块和资源不在本次改动范围。
- 数据使用 `var/fixed-building-pressure/`，API 使用 `/api/architecture/pressure/`。旧工作台在新资源不可用时仍能访问。
- 安装资源只含六个保留结构输入与显示元数据；导出基于用户提供的压力时程。空气边界仅作参考显示，没有加入空气/爆源求解文件。
- 主工作区已有未提交内容、已有暂存说明文档、其他隔离工作树和历史测试结果全部保留。合并前快照保存在 `artifacts/fixed-building-merge-20261016-01/`。

## 专项验证

干净集成工作树通过 47 项相关测试：固定建筑资源与缓存、压力载荷和导出、正式 HTTP 保存/预览/下载（两立方体夹具）、JSON 与同源校验、HEAD、旧静态入口在新模板不可用时的隔离、旧服务器路由及端口独占。另用全新进程禁用 NumPy，确认原应用仍能启动、旧页面与 API 可用，仅新压力 API 返回 503。独立审查发现的提前加载依赖问题已修复，复核无剩余阻塞项。

10 月 13 日已通过的 14 项集成预览浏览器检查与独立审查记录保留。合并后另在实际主工作区运行更新的浏览器脚本，增加原精细化建筑爆炸入口及返回操作；结果记录在上述合并证据目录。此次不启动原生求解器，不执行全量或真实重型案例。
