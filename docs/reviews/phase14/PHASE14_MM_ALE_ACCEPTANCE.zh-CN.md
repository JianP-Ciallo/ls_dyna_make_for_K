# Phase 14 MM-ALE 求解验收状态

## 当前结论

Phase 14 的 MM-ALE 建模和求解链路可继续使用，但旧的三档
`coarse/baseline/fine` 收敛报告已经降级为历史无效证据。旧运行缺少运行级
`model.json` 和证据清单，不能证明报告中的网格尺寸、输入文件和输出文件就是
实际求解时使用的版本。

旧报告中的 `converged=true` 不再作为验收结论。重新求解前，只能引用旧运行
作为调试和历史对照，不得引用为网格收敛、工程预测或材料标定证据。

## 新运行验收门禁

新的 Phase 14 运行结束后会生成 `evidence_manifest.json`，并在运行记录中保存
清单 SHA-256。清单绑定：

- `model.k`
- `model.json`
- `d3hsp` 和可选 `glstat`
- `dbfsi`
- `nodout`
- 全部 `d3plot*` 文件

终态刷新和收敛比较会重新核对清单、输入哈希、模型哈希以及
`latest.json`/`run.json` 身份。缺失清单或任一文件变化时，结果为
`invalid_evidence`。

该机制用于防止意外覆盖、后处理误写和普通工作流中的证据漂移。它不是数字签名：
能够同时改写运行文件、清单和两份运行记录的本机管理员仍可伪造整套证据。需要
对抗此类主动篡改时，应把清单摘要发送到只读外部存储或使用受保护密钥签名。

传播验收还要求：

- 只有一个目标钢板耦合卡、一个 D3HSP FSI interface 和一个 DBFSI surface；
- DBFSI surface ID 与 D3HSP interface ID 一致；
- 响应节点属于被耦合的目标钢板壳单元；
- 响应节点不在约束平动自由度的节点集中；
- 压力、合力、冲量和位移均超过数值噪声门限；
- 压力具有至少两个有效样本和非零持续时间；
- 钢板位移峰值不早于耦合压力峰值。

这些门禁证明的是“受控模型产生了可辨识的 FSI 载荷传递和钢板响应”，不代表
材料已经过实验标定。

## 网格收敛

新的收敛比较只接受已经通过求解器终态验收的封存运行。网格尺寸必须同时来自
运行级 `model.json` 和运行记录 `blast_configuration.mesh_sizes_m`，两者必须
一致。

三档网格还必须满足：

- 相邻细化比不小于 `1.10`；
- 两个细化比的比值不大于 `1.20`；
- 响应序列单调；
- 观测阶次为正有限值；
- 使用安全系数 `1.25` 计算的 finest-grid GCI 不超过指定容差。

因此，重新执行三档真实 LS-DYNA 求解后，可能得到
`not_converged`。这表示需要增加或调整网格级别，不能通过修改报告或重新标注
网格尺寸绕过。
