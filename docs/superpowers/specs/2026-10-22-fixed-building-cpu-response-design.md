## 1. 用户已确认的目标与本次修订

在“固定建筑压力分析”里，以 CPU 计算爆炸荷载作用下的结构响应。先完成单柱、单板小算例，查看实际耗时、变形云图和钢筋应力；方法与性能验证通过后，再扩展到现有三层建筑。采用有出处的工程方法与参考参数，说明适用范围，保留原来的建模与 K 文件导出流程。

本版替代原来的“先做三层九自由度整体响应，再接页面”安排：

| 原安排 | 修订后的安排 |
| --- | --- |
| 三层、9 自由度作为首版生产模型 | 单柱纤维梁柱、单板分层配筋壳先行，再建立建筑构件模型 |

实施步骤和后续执行证据见 [实施计划](../plans/2026-10-22-fixed-building-cpu-response.md)。本版最初为文档修订，后续由用户“开始吧”授权实施。

## 2. 当前仓库事实与边界

- `/fixed-building-pressure` 是 Three.js 建筑预览；`/structural-pressure` 提供外部压力时程、受载面、监测、工况保存和 K 包导出。
- 接口前缀 `/api/architecture/pressure/` 已有严格字段检查、模板指纹和工况版本；Web 入口拒绝 API 查询参数，并检查本地来源与 JSON 请求。
- 固定模板有 831 个语义构件，包括 36 根柱、125 个墙构件、28 个楼板和 9 个屋面构件；没有独立 `beam` 角色。显示构件数不等于计算单元数，墙角色不等于承重混凝土墙。
- 当前几何预览允许包围盒回退，只能用于显示；求解几何、体积和连接必须另行核验。
- 原压力工况只有一个 `component_id + face`，不是整栋立面加载；当前曲线只接受非负压力，起点 `[0,0]`、终点压力 0。负压阶段及非零起始压力不能偷偷截断后导入。
- `PressureService.save()` 覆盖同一 scene 的最新记录；任务不能只保存 scene_id/revision，必须冻结完整输入。
- 编制设计时尚无 CPU 响应内核；后续首版已接入单柱/单板弹性内核及钢筋应力接口。经验爆炸荷载生成器与整栋计算仍未开放。现有混凝土参考材料不构成实际建筑的标定数据。

## 4. 数值方法与参数来源

### 4.1 求解内核与运行环境

采用 OpenSeesPy 作为候选主内核，避免从零开发梁柱、分层壳与非线性材料求解器。Windows 参考候选为 Python 3.12 x64、`openseespy==3.8.0.0` / `openseespywin==3.8.0.0`；这是待实际导入与小探针验证的组合，不根据 PyPI 的 `Python >=3.12` 字段宣称任意新解释器都兼容。

实施时在项目内独立环境运行，不降级或污染主工作台 Python。依赖可选、延迟导入，未安装时能力接口给出 unavailable，原预览及 K 页继续可用。工作进程启动参数只由服务端产生，HTTP 不接受 Python、脚本或文件系统路径。记录最终解释器、内核版本、依赖锁和线程设置；本地研究使用与打包分发的许可证核对分开处理。

采用稀疏结构求解、Newmark 平均加速度法（γ=1/2、β=1/4）。非线性迭代不收敛时回退到最后已提交状态，只按预设次数减小时间步；超过预算即失败并保留诊断，不能继续输出成功。积分时间步由压力上升段、目标结构频率与收敛检查确定，不能由动画帧率决定；平均加速度法的稳定性不代表任意步长都准确。

首批采用显式节点集总平移质量，关闭原生单元/材料质量贡献，避免叠加。柱线质量为 `μ=ρc(A−ΣAs)+ρsΣAs`，每段质量各半分配到两端；板面质量为 `mA=ρc(h−Σts)+ρsΣts`，每个矩形单元质量各四分之一分配到四节点。忽略截面/板厚旋转惯性，明确这一低阶近似，并通过空间细化及独立一阶周期检查验证。总质量在施加约束前核对，固定/自由节点的份额另列账目；不能只检查约束后的活动质量。

### 4.2 参数分层与材料能力

所有参数记录值、SI 单位、来源、用途、适用范围、版本及修改说明。材料参数分为“纯数值验证”“文献复现”“本建筑参考”三类，不把参考值称为实际设计值。混凝土强度类型与换算明确，不直接把 C30 的立方体名义强度填作所有本构的单轴抗压参数。

首轮先做线弹性混凝土与弹性钢筋基线，输出真实的弹性钢筋应力；在基线通过后，单柱增加 Concrete02/Steel02 材料专项及轴弯响应。板的非线性混凝土采用经过独立验证的平面应力材料加分层壳；未完成该验证时，板结果标为弹性，不开放开裂后钢筋屈服判断。单轴混凝土模型不能直接充当板的多轴材料。

Steel02 本身不是完整的爆炸率相关钢筋模型。动力增强可在资料规定的条件下构成单独参数方案；同一机制不得与率相关本构重复叠加。纯数值基线采用零阻尼；物理比较的阻尼需有来源并做敏感性对照，不沿用原版 2% 作为通用爆炸常数。

钢筋与混凝土首批采用完全粘结、共同变形。模型不模拟粘结滑移、钢筋断裂、局部屈曲、混凝土剥落、碎片或倒塌。普通纤维梁主要描述轴力与弯曲；爆炸下剪切、冲切等模式另设能力边界，不能由弯曲响应直接推断。

### 4.3 单柱参考算例

- ID：`rc-column-v1`；竖向悬臂，长度 3.0 m，矩形 0.30×0.30 m，底部六自由度固定，顶部自由。压力沿指定水平面法线作用于柱一侧，先测试无轴向预载，再单独增加有出处的重力/轴力方案。
- 数值配筋：四角 4 根直径 16 mm 纵筋，保护层 40 mm（到钢筋表面）；显式转换到钢筋中心。箍筋只在经验证的约束混凝土参数方案中参与，不宣称输出每个箍筋的应力。
- 初始网格 4 段梁柱，网格检查 8、16 段；截面积分点及混凝土纤维数写入快照，并与 2 倍截面细化作独立检查，不能只检查梁段数。
- 弹性纯数值参数：混凝土 E=30 GPa、ν=0.2，钢筋 E=200 GPa；混凝土/钢筋密度分别 2500/7850 kg/m³。以上为数值参考输入，不代表实际建筑材料等级已确定。截面刚度与质量扣除钢筋占用混凝土体积，避免重复计算。
- 弹性静力对照采用同一组合截面的 EI：均布线荷载 q 下，顶位移 `qL⁴/(8EI)`、底弯矩 `qL²/2`；恢复钢筋位置处的应变及 `σs=Es·εs`，仅在弹性测试中使用此关系。
- 动力基线为明确给定的表面压力折线，映射为一致节点力，不把所有压力集中到柱顶。输出顶位移、速度、加速度、底反力、截面曲率、各纵筋纤维应力/应变及发生位置和时间。

### 4.4 单板参考算例

- ID：`rc-panel-v1`；2.0×2.0 m、厚 0.15 m 的水平板，四边简支受法向压力。边界固定边缘法向位移，另用最少面内约束去除刚体运动，不能把简支误设成四边固支。
- 数值配筋：上下各双向直径 10 mm、间距 200 mm、保护层 25 mm（到钢筋表面）。记录四层配筋的实际中心位置、上下层和局部方向；交叉钢筋按叠放位置布置，不把所有钢筋放在中面。
- 使用 `ShellMITC4 + LayeredShell + PlateRebar` 候选组合；混凝土采用与板壳兼容的多轴材料。S0 必须实测这一组合的材料复制、局部坐标、钢筋层记录器与结果含义，不以 API 名称存在代替验证。
- 初始网格 4×4，检查 8×8、16×16。配筋等效厚度 `ts=单根面积/间距`，层位置按物理钢筋中心保留；混凝土层与钢筋层总体积/厚度及质量需一致。首批质量按第 4.1 节统一分配，不依赖 PlateRebar 是否自带密度，原生质量与节点质量不能叠加。
- 不配筋的薄弹性方板另作解析基线，中心挠度参照 Navier 解并报告剪切变形、离散与薄板假设差异；不能拿这个公式直接验收已改变刚度的配筋板。
- 配筋板另用等曲率材料/截面检查，并采用对称正交层合板的独立 Navier 级数参考：由实际各层位置和刚度积分得到 D11、D22、D12、D66，核对膜弯耦合 B=0，再比较同一边界下的中心挠度，目标差异 ≤5%。级数自身先做截断收敛，说明薄板与壳剪切差异。输出节点挠度、板中测点曲线、反力、上下/双向配筋层轴向应力和应变；方向旋转测试核对 0°/90° 与局部坐标，不能把板壳合力当钢筋应力。

### 4.5 参考荷载与经验爆炸荷载

S1 使用可解析、可复现的给定压力，区分静力参考与动态参考：动态折线 `[0,0] → [1 ms,10 kPa] → [10 ms,0] → [150 ms,0]`，初始积分步长 0.1 ms，同时做 0.05 ms 对照。幅值与时间仅用于数值和性能验证，不能称为一组通用真实爆炸参数；若响应超出弹性适用范围则降低幅值并保存新算例版本，不修改既有结果。

S3 在独立 CPU 荷载配置中增加经验来源模式：采用有出处、版本与使用条件的 Kingery–Bulmash/CONWEP 类实现或经校验参考表，限定室外自由场/地面爆炸的已验证范围。先冻结一套可使用的实现或参考表及对应测点数据，再编码适配；来源不明、许可不允许使用或不通过对照时不开放该模式，已有外部时程仍可用。此选择不假定任何商业软件实现可直接复制或再分发。

经验模式输入爆源位置、当量、类型等工况信息，按受载位置计算到达时间、峰值、冲量与入射/反射表面压力，输出 `p(x,t)`。地面爆炸模型自身包含的地面效应与建筑多次反射分开说明。复杂遮挡、绕射、室内传播与流固双向反馈不在本方案中；禁止补画传播波前冒充空气域求解。

外部时程模式保留现有单构件单面语义，单位 ms/kPa→s/Pa；压力映射保持合力、力矩与冲量。当前不支持的负压曲线显式拒绝或转入独立且已验证的 CPU 输入模式，不能静默裁剪。经验 CPU 荷载不会自动写入旧 K 工况，除非另行完成可审查的格式转换与专项验证。

## 5. 云图、曲线与 CPU 性能证据

### 5.1 结果含义与可视化

三种量分别提供选择器和色标：表面施加压力（kPa）、计算位移（mm）、钢筋轴向应力（MPa，拉正压负）。位移绘图可选分量或模长；应力选择纵筋编号，或配筋层的上/下、X/Y 方向，不能混成无定义的单一“钢筋应力”。

柱变形使用计算梁节点与相应梁插值；钢筋应力按截面积分点绘制，可插值显示，但原始采样点与未平滑峰值可查询。板使用板壳节点回放挠曲，配筋层应力先按单元/积分点显示。平滑和变形放大只改变显示，峰值与超限判断始终取实际内部结果。基础不动，每帧从原始坐标计算，避免累计漂移。

压力云图是输入荷载场的显示；位移和钢筋应力是结构计算结果。经验表面压力不标为空气压力场。弹性模型不提供屈服/损伤图；非线性模型只有在对应材料与构件验证通过后，才显示相应状态。

### 5.2 性能测量与预算

报告分开记录建模、求解、应力提取、写盘/压缩、结果加载和首帧渲染；另记录排队时间、端到端墙钟时间、工作进程 CPU 时间、峰值 RSS、数据体积、CPU/内存/操作系统/Python/内核版本、线程数、网格/自由度/纤维/积分点、实际步数、迭代和回退次数。

同一配置区分首次启动和预热后运行；正式小样本性能记录一次冷启动与三次预热后独立建模/求解的中位数及范围。冷启动包含进程启动和内核导入，预热实验在同一隔离 worker 中逐次清空模型并重新建模，不复用上一遍位移或材料状态。报告明确 worker 是否复用，不把预热求解时间称为每次重启进程的端到端时间。不把排队时间算作求解时间，不把三次回放当作三次求解。计时采用单调时钟；内核推进和应力读取分别累计互不重叠的区间，原生内存用进程 RSS 采样观测并注明采样周期，不仅用 Python 对象追踪。

首轮资源上限：每个真实小算例墙钟 30 s，单条验证/性能命令总预算 180 s；最多 1 个计算工作进程，最大 10,000 个实际积分步、500 个动画帧、5,000 个曲线样本。超限则停止并报告 timeout/budget_exceeded，不自动放粗时间步或写成通过。网格/步长矩阵分组显式运行，不加入默认 smoke，不启动任何真实整栋建筑求解。

墙钟预算由父进程的单调时钟看护强制执行，不能仅依赖 worker 在两次 analyze() 之间检查。取消或超时后，先请求退出；原生调用仍阻塞时终止本次拥有的 worker 并等待回收。180 s 覆盖启动、导入、预热、重复求解、提取与写盘；正常预算预留回收余量，终止/回收耗时单列。不得误终止无关 Python 或外部求解进程。

这些数值是试验预算，不是已测性能或保证的完成时长。未完成的矩阵报告为部分完成。S4 的预算必须由小样本结果和实际建筑规模重新估计，不能直接外推成“整栋几十秒”。

## 6. 页面、K 导出与三层建筑映射

保留“固定建筑压力分析”总入口以及三个工作区：

| 页签 | 路由 | 职责 |
| --- | --- | --- |
| 建筑预览 | `/fixed-building-pressure` | 原建筑、房间、楼层、剖切 |
| 工况与 K 文件 | `/structural-pressure?scene_id=<id>` | 原压力编辑、保存、校验和 K 导出 |
| CPU 响应 | `/fixed-building-pressure/response` | 小算例选择、参数与范围、显式计算、回放与性能报告 |

S2 先在 CPU 页提供单柱/单板选择，三层建筑显示“完成构件映射后开放”。小算例采用独立 benchmark_id/revision，不伪造 scene_id。S4 后支持 `?scene_id=<id>`；查看历史结果使用 run_id，服务端核对所属来源。旧路由可直接访问，API 继续采用无查询参数的路径接口。

CPU 页左侧参数/荷载来源，中部三维与字段切换，底部时间轴和曲线，右侧指标、性能和假设。空状态不填造结果；显示 queued/running/completed/failed/cancelled/interrupted，计算时可停止。先计算完成再回放，不要求实时传帧。颜色、图标、文案和组件使用本项目设计，不复制对方网站的源码、品牌或模型。

S4 另建“语义构件→梁柱/板壳→显示网格”映射。核验真实几何、材料、楼层、承重体系、钢筋位置与截面、连接及边界；缺失梁角色不能随意生成虚构梁，也不能继续把所有柱端强制固定来掩盖连接问题。根据核实结构采用柱板体系、明确新增参考梁或补齐实际结构信息，映射方案与模板指纹一起保存。先做单跨柱板小装配，再做三层。

本轮 S4 决策：原生柱部件只占标称方柱的一部分，其他体积归墙等部件；同时语义 plaster 外墙在原 K 实际指定9002混凝土。用户已明确选择独立 CPU 规整方案：由设计顶点恢复300×300 mm柱，扣除原所有者的相应体积与质量，原 K 不改；其余板片仍须先证明与真实原生矩形实体吻合，不能包围盒回退。墙等按用户选定的非承重角色处理，但保留原材料卡质量。这是有记录的参考模型差异，不宣称复现原 K 的刚度。

柱保留原始四根Φ16坐标，允许不对称；板保留四层Φ16实际层位及等体积配筋层，B不强制为零。柱链与板中面共节点，接头区采用明确的轴线理想化；地坪及柱脚固定。填充/楼梯/超高顶盖只计附加质量及压力传力，偏心集总模型不求其局部振型。除了总质量、重心及惯性，还分别核对板质量归本层、柱筋归柱链及本层独立平动动能；不能用整体守恒掩盖局部分配错误。墙按实际净跨分配简支反力，之后只映射支承面至壳中面的真实偏心，不添加跨高的附加端矩。真实三层首次全域弹性计算已完成且在预算内，尚不能代替整栋网格/时间收敛与工程准确性验证。

承重墙、井筒、填充墙、非结构构件的刚度/质量贡献明确分类；附属构件可随宿主运动，但不能显示未计算的钢筋应力。楼板使用板壳时不能再用整层刚性约束消除待观察的局部挠曲。梁壳连接、偏心与截面重叠按明确规则校核，不通过随意节点合并或补小刚度消除机构。

CPU 与 K 共用模板与明确可对应的工况来源；CPU 材料、配筋、约束、动力增强、积分及输出配置独立保存，不静默改写 K。CPU 不支持的原实体/地面应力监测标明不适用，不能填零；支持的测点单独映射到求解节点或积分点。两种结果明确标识模型差异。

三页跳转携带保存后的工况身份；未保存输入提供保存并跳转/留在当前页。页面 GET、打开历史结果不保存配置、不计算、不导出。压力修订与 CPU 配置变化产生新身份，旧结果保留并显示其输入版本。

## 7. 数据、任务与接口约定

新增包 `lsprepost_mcp/architecture/cpu_response/`，将合同/参数、荷载、柱、板、内核适配、结果、性能、建筑映射、存储与任务分开。前端仍位于 `lsprepost_mcp/web/static/`，不修改归档 React 原型。

CPU 数据在固定建筑工作区的 `cpu_response/` 下，记录配置、不可变输入、任务、结果与产物哈希。来源是 `benchmark` 或 `pressure_scene`，身份含来源 ID/revision/指纹；快照含完整参数和来源账目、几何/拓扑/配筋、实际载荷场、参考数据版本、依赖与内核版本、数值/输出设置、显示映射和支持字段。不得只保存原工况位置或外部文件引用。

新增 API 前缀 `/api/architecture/pressure/cpu-response/`：

| 方法 | 相对路径 | 行为 |
| --- | --- | --- |
| GET | `capabilities`、`benchmarks` | 读取已保存的环境验证记录、预算和参考算例元数据；不生成模型或启动工作进程。无匹配环境记录则标未验证 |
| POST / GET | `profiles` / `profiles/{profile_id}` | 校验并创建不可变 CPU 配置 / 读取配置 |
| POST | `preflight` | 检查来源身份、配置、模型与预算，返回规范化摘要和指纹 |
| POST | `runs` | 原子核对身份与预算，冻结完整快照，显式提交并返回 202 |
| GET | `sources/{kind}/{source_id}/runs`、`runs/{run_id}` | 读取来源历史、任务阶段和摘要 |
| POST | `runs/{run_id}/cancel` | 取消排队或运行任务 |
| GET | `runs/{run_id}/results`、`runs/{run_id}/artifacts/{name}` | 验证哈希后读取结果或下载白名单产物 |

沿用严格字段、ID 和本地来源检查。结果产物有自己的 JSON/CSV/PNG MIME，不能沿用现有 request() 对全部 bytes 一律包装成 ZIP 的分支。GET/HEAD 行为一致且 HEAD 无实体。profile、run 和产物 ID 不接受路径穿越。

最多一个计算工作进程；同一幂等提交标识不创建重复任务。队列冻结的快照不随后续编辑变化；进程返回结果时核对 run 身份、退出状态与产物完整性。取消和服务重启分别标 cancelled/interrupted，不把部分帧标为成功。页面切换来源、配置、run 或字段时丢弃旧异步响应。

## 8. 精度、物理范围与阶段门槛

以下为验收目标。当前弹性参考算例的静力、质量/频率、钢筋读取及 16→32 / 32 网格步长减半检查已通过；经验荷载、非线性与实际整栋验证仍待完成。详细数据和保留的历史失败见实施记录。

| 检查 | 目标及证据 |
| --- | --- |
| 单柱弹性静力、截面钢筋应力 | 与同一组合截面解析值的非零量相对误差 ≤2%；零参考量按明确绝对容差 |
| 裸弹性板解析基线 | 网格细化后中心挠度与相应薄板解差异 ≤5%，说明剪切和边界假设 |
| 质量与绝对动力参考 | μ、mA 与总质量独立核对；悬臂柱一阶弯曲频率按 `ω1=1.87510407²√(EI/(μL⁴))`，细化后差异 ≤2%；裸简支板按 `ω11=π²√(D/mA)(1/a²+1/b²)`，目标差异 ≤5%，报告壳剪切/旋转惯性近似 |
| 配筋截面/配筋层 | 刚度、面积与位置恢复，弹性钢筋 `Es·εs` 对照，局部坐标旋转后等价 |
| 动力数值收敛 | 步长减半、空间细化分别检查；主响应峰值变化 ≤2%，周期/峰时变化 ≤2% 或一个较粗步长；零量用预先声明的绝对容差 |
| 荷载映射与反力 | 单位、法线、合力、力矩、冲量及支座反力守恒，不因网格变化改变总荷载 |
| 应力结果真实性 | 有元素/截面/积分点/钢筋或配筋层标识；非空、非伪造，原始峰值与显示平滑区分 |
| 非线性功能 | 材料路径与公开参考对照、残余变形/应力可追踪；仅材料单轴测试不能替代构件级验证 |
| 经验荷载 | 在冻结适用域内，与选定参考测点的到达时间、压力峰值、冲量逐项对照并记录误差；通过前能力保持关闭 |
| 性能 | 按第 5 节记录实际数据，成功、超时、取消、未运行分别列示 |

无阻尼弹性自由振动必须采用非零初始位移/速度，或经已知加载卸载形成非零状态后检查周期与能量，避免零响应空通过；非线性模型检查外功、动能、耗散和数值异常，不能要求有塑性耗散时机械能恒定。所有相对误差只用于非零参考量，绝对容差按各量 SI 尺度在测试夹具中固定。

这些指标验证实现和特定参考模型，不代表相对真实爆炸或本建筑的误差只有 2%/5%。缺少试验或可比的高保真结果时写明缺口。已保存 LS-DYNA 结果只做条件一致的只读对照，不为补证据自动启动 LS-DYNA。
