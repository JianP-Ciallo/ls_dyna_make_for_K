# Phase 18 三类实体建筑 MM-ALE/FSI 爆炸模型设计

状态：用户已批准方案 A 与修正后的混合单元原则，待书面规格复核

日期：2026-08-20

单位制：`SI_m_s_kg_N_Pa`

## 1. 唯一目标

为商业超市、住宅社区和地铁入口生成三套能够被 LS-PrePost 正确导入、由 LS-DYNA R12 实际求解的爆炸模型。每套模型必须同时具备：

1. 具有现实承重路径和围护构造的实体建筑；
2. 可见、带真实空气材料和状态方程的三维 MM-ALE 空气域；
3. 质量、位置和起爆时刻可修改的球形 TNT 爆源；
4. 能把能量按“炸药 → 空气 → 建筑”传递的真实 FSI 耦合；
5. 可追溯的 LS-PrePost 导入、LS-DYNA `mcheck` 和 1 ms 爆炸求解证据。

本设计新增独立的 solver-complete 编译器。它消费既有 Phase 18D 建筑语义，但不把 Phase 18E 的中性候选片段或此前的重力验证 K 文件冒充可求解爆炸模型。

## 2. 修正后的单元选择原则

`Solid`、`Shell` 和 `Beam` 可以同时存在。禁止的是没有物理依据的任意混用，而不是禁止某一种单元。

每个构件在清单中必须记录物理角色、真实尺寸、采用的单元族、选择依据、材料、连接方式和可暴露表面。编译器按以下规则选择：

| 构件 | 默认单元 | 物理依据 |
|---|---|---|
| 基础、承台、筏板、厚楼板、RC 柱/梁/墙、地下箱体、楼梯、土体 | Solid | 需要实体体积、质量和三向应力/接触 |
| 砌体、预制混凝土或实体围护墙 | Solid | 不允许以无厚度视觉外壳替代实体墙 |
| 薄钢板、金属屋面、玻璃幕墙、薄栏板 | Shell | 厚度远小于面内尺度，记录真实厚度和积分点 |
| 细长钢柱、钢梁、钢筋、栏杆 | Beam | 长细比满足梁理论，记录真实截面、方向和积分属性 |
| 不满足薄壁或细长条件的局部钢节点/厚板 | Solid | 局部三向应力或连接响应不可由梁壳可靠代表 |

建议门限为：梁构件 `L / max(section_dimension) >= 10`；壳构件 `characteristic_in_plane_length / thickness >= 10`。低于门限时改用 Solid，或者由审查记录明确说明例外。

不同单元族之间必须通过共享节点、受控嵌入、节点/面约束或已校验接触连接。仅在画面中相交、悬空端点、重复重叠、未声明穿透和未连接的围护均为硬错误。

## 3. 三类建筑的物理模型

### 3.1 商业超市

- RC 筏板、基础、主要楼板和承重核心采用 Solid。
- 钢框架保留真实钢柱、钢梁和开口门架；细长且截面响应适用时使用 Beam，否则局部节点使用 Solid。
- 不透明外墙改为有实际厚度的实体砌体/预制墙 Solid，门窗洞口保持为空腔，不再用整片非承重 Shell 冒充墙体。
- 玻璃和薄金属屋面使用有真实厚度的 Shell，并与边框可靠连接。
- 必须存在从屋面/楼板经梁柱到基础的连续承重路径；每根承重柱在清单中可追溯。

### 3.2 住宅社区

- RC 基础、柱、梁、剪力墙、核心筒、楼板和阳台板采用 Solid。
- 钢筋可采用真实截面的 Beam 并通过受控嵌入连接到混凝土；若使用等效配筋材料，必须单独标记且不得同时重复布置显式钢筋。
- 不透明围护墙采用有厚度的 Solid；窗玻璃和薄栏板可采用 Shell。
- 修复当前逐层围护的水平断带：上一层围护、楼板边缘和下一层围护必须形成符合建筑构造的连续边界，不能留下无设计依据的 0.2 m 空层。
- 塔楼之间不建立虚假连接；每座塔楼各自通过基础把荷载传至地基。

### 3.3 地铁入口

- 地下 RC 箱体的底板、侧墙、顶板、楼梯、平台和出入口基座采用 Solid。
- 地上雨棚/亭体的钢框架按长细比使用 Beam 或 Solid；玻璃和薄屋面使用有真实厚度的 Shell。
- 增加实体土体和可见地面。默认站厅/通道箱体埋于土体中，地面标高由资产几何推导并写入清单。
- 土体在 RC 箱体和开放入口体积处开挖，不得与 RC、楼梯或通行空气空间正体积重叠。
- 地面以上空气和入口连通空气形成爆炸流体区域；封闭土体不属于空气域。

## 4. 空气域、爆源与地面

### 4.1 MM-ALE 空气域

- 使用三维结构化六面体 ALE 网格，作为 LS-PrePost 中可独立显示的空气 Part。
- 采用 `*MAT_NULL`、空气 EOS、ALE Section、`*ALE_MULTI-MATERIAL_GROUP` 和 `*CONTROL_ALE`。
- 空气域由建筑/土体包围盒和可配置边距确定；除反射地面外的远场边界采用已校验的非反射边界。
- 生成前估算轴点、节点、单元、内存和文件大小；超预算直接拒绝，不能静默粗化。
- 空气域必须覆盖爆源和所有需要传播的外部空间，并在预览、K 文件和 manifest 中保持同一边界与身份。

### 4.2 可移动 TNT 爆源

公共参数为：

- `tnt_equivalent_mass_kg`：允许 `0.1–100 kg`，默认 `2 kg`；
- `charge_position_m=[x,y,z]`：三维位置可修改；
- `detonation_time_s`：默认 `0 s`；
- TNT 半径由质量和受控密度计算，不允许用户同时提供矛盾半径。

爆源使用 `*MAT_HIGH_EXPLOSIVE_BURN`、`*EOS_JWL`、`*INITIAL_VOLUME_FRACTION_GEOMETRY` 和 `*INITIAL_DETONATION`。爆源必须位于有效空气体积内，不得处于建筑、土体、地面以下或空气域外。爆源与建筑、土体和外边界的最小间距由药包半径和本地网格尺寸共同确定。

软件允许范围不等于全部工程验证范围。首轮 1 ms 求解使用默认 `2 kg` 完成证据闭环；其他质量必须重新执行网格分辨率、空气域、稳定时间步和结果审查。

仅修改爆源质量、位置或起爆时刻时，建筑网格指纹必须保持不变；工况和最终 K 包指纹必须改变。

### 4.3 土体和支承

- 商业与住宅模型包含基础下方的实体诊断土层和可见地面；地基边界固定在土层远端，而不是直接固定建筑最低节点。
- 地铁模型包含围绕地下 RC 箱体的实体土体，明确记录开挖体和地面标高。
- 首轮土体和结构材料属于可追溯的诊断/研究候选参数，不宣称完成场地或材料试验标定。

## 5. FSI 与连接闭包

建筑外表面、洞口边界和地面表面从实际单元拓扑重新提取，不能信任仅由目录声明的面积或法向。

`*CONSTRAINED_LAGRANGE_IN_SOLID` 必须引用：

1. 非空且由真实外边界面组成的 Lagrangian slave segment set；
2. 当前 MM-ALE 空气/TNT master part set；
3. 与采用的侵蚀设置一致的耦合类型和方向。

硬性门禁：

- 每个 FSI 面确实是 Solid 或 Shell 的外边界面；
- 面法向、面积和节点顺序可由网格重新计算；
- 不允许内部面、重复面、零面积面或悬空节点；
- LS-DYNA `d3hsp` 报告的 slave segment 数必须大于零；
- 不以“存在 `dbfsi` 文件”替代有效耦合证据。

## 6. 生成架构

新增 `refined_building/solver_blast/` 子系统，职责分离如下：

```text
physical_building.py   # 物理构件选择、连接和三类资产修正
ground.py              # 地面、土体和开挖体
ale_domain.py          # 有界结构化 MM-ALE 网格与边界
charge.py              # TNT 质量、位置、体积分数和起爆
fsi.py                 # 真实外表面、集合和耦合
keyword.py             # 依赖闭合的 LS-DYNA 卡片
validation.py          # 静态、几何、关键字和持久化审查
results.py             # mcheck、1 ms、能量与波传递证据
service.py             # 三类模型的生成与验收入口
```

此前的 `solver_validation.py` 保持为“重力结构初始化”工具；Phase 18E 中性 Provider 保持软件候选边界。新编译器复用已经经过真实求解验证的 Phase 14/15 ALE、TNT 和 FSI 卡片模式，但必须重新验证三维字段、ID、单位和 R12 兼容性。

每个生成包采用依赖闭合的单体 `model.k`，同时写出 `model.json`、`manifest.json` 和 `validation.json`。运行产物写入新的独立目录，不覆盖此前三套结构诊断模型。

## 7. 错误处理与审查

以下任一条件必须在启动 LS-DYNA 前失败：

- 构件单元族缺少物理选择依据；
- 梁截面、壳厚度、Solid 体积或材料缺失；
- 连接悬空、重复、穿透、未声明或载荷路径中断；
- 围护空隙不是显式洞口；
- 土体与建筑/通行空间重叠；
- 爆源不在有效空气体积或分辨率不足；
- ALE/FSI 集合为空、面不真实或 ID/Include 闭包不完整；
- 生成文件哈希、计数或单位无法重新计算一致。

LS-PrePost 导入错误必须保存原始消息、日志或截图，不允许只记录“导入失败”。LS-DYNA 错误必须追踪到材料、几何、关键字、连接或求解控制的生成源，并以失败测试复现后再修复。

## 8. 验收合同

### 8.1 自动化软件门禁

- 三类建筑均通过物理构件审计和单元选择审计。
- 建筑没有重复单元、负/零体积、缺失节点、无依据围护缺口或未连接构件。
- 空气域、TNT、土体、建筑、边界和 FSI 的节点/单元/Part/Set 引用闭合。
- 改变爆源位置保持建筑指纹不变，同时改变工况和 K 包指纹。
- 关键字中存在且可重解析空气、TNT、ALE、多材料初始化、起爆和 FSI 卡片。

### 8.2 LS-PrePost 与 LS-DYNA 门禁

每套默认模型必须依次完成：

1. LS-PrePost 正确导入，空气、TNT、建筑和土体可分 Part 显示；
2. LS-DYNA R12 `mcheck=y` 无真实 Error；
3. 默认 `2 kg` TNT 工况求解达到 `1 ms` 并正常终止；
4. 能量和状态值有限，无 NaN、负体积、fatal error 或未审查的严重警告；
5. `d3hsp` 中有效 FSI slave segment 数大于零；
6. 爆源/空气域出现非零有限压力与内能变化；
7. 至少一个建筑探针出现超过数值噪声的有限压力、速度、应力或应变响应；
8. 到时满足爆源先响应、空气后响应、建筑再响应的因果顺序。

只有三套模型分别保存上述终态证据，才能称为“三项齐全的最终 PASS”。

### 8.3 工程边界

1 ms PASS 证明的是关键字、几何、耦合和短时爆炸传播链可以运行，不证明材料破坏、倒塌、峰值压力或工程安全预测已标定。因此产物继续保持：

- `engineering_validated=false`
- `requires_project_review=true`
- `solver_ready=false`，直到具体快照通过本设计的全部求解门禁；即使快照通过，也只允许标记该快照为 `solver_initialization_checked=true` 和 `wave_transfer_verified=true`，不提升全局工程验证状态。

## 10. 非目标

- 不把 1 ms 验证称为完整爆炸响应或抗爆设计结论。
- 不为追求通过而隐藏 LS-DYNA 警告、降低审查门限或删除真实构件。
- 不在本阶段做 100 ms 全时程、网格收敛、材料试验标定、破坏/倒塌预测或 0.1–100 kg 全范围批量求解。
- 不修改其他城市工况、旧工作台项目或此前结构诊断证据。
