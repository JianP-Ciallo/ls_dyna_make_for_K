# Phase 11.9 开发审查分发包设计

## 目标

生成一份面向开发与复核人员的完整 zip 分发包。使用者解压后既可以双击启动 Web App，也可以检查源码、运行测试、配置 AI IDE/MCP，并复核 LS-PrePost 与 LS-Run 交接行为。

## 包含内容

- `lsprepost_mcp/` 后端与 Web App 源码。
- `scripts/` 启动、诊断、测试、配置和打包脚本。
- `tests/` 单元测试与集成测试入口。
- `examples/` 可复核示例和 MCP 配置模板。
- `templates/`、`materials/`、`web/` 和项目文档。
- 根目录 README、AI IDE 启动说明和一键启动入口。

## 排除内容

- `.git`、`dist`、`workspace`、`projects` 和 `generated_configs`。
- Python 缓存、测试缓存、LS-PrePost 临时文件和历史压缩包。
- 本机绝对路径、本机 LS-PrePost/LS-Run/LS-DYNA 配置和用户生成模型。
- 专利草稿、渲染中间目录和内部设计过程文档。

## README 结构

根目录 `README.md` 作为首要入口，使用简明中文说明：

1. 项目定位和能力边界。
2. Windows、Python、LS-PrePost、LS-Run/LS-DYNA 的要求。
3. 双击 `start_web_app.cmd` 的一键启动方式。
4. 在 Web App 中导入 LS-PrePost、LS-Run 和 LS-DYNA 可执行文件的方法。
5. 四个受控场景与主要可填写参数。
6. 生成、三维预览、保存、LS-PrePost 复核和 LS-Run 交接流程。
7. AI IDE/MCP 的只读使用入口。
8. 测试、打包和常见故障处理。

README 必须明确：当前 LS-Run 能力只负责校验本机路径、保存本地配置并打开 LS-Run 完成交接；尚不保证自动填入作业、自动启动 LS-DYNA、监控求解或判断结果。

## 包名

使用阶段和能力命名：

```text
lsprepost-mcp_phase11.9-lsrun-handoff-dev_<UTC_TIMESTAMP>.zip
```

新包带时间戳且不覆盖旧包。

## 验收

- 完整单元测试通过，允许依赖真实 GUI 的集成测试按既有条件跳过。
- Python 包编译检查通过。
- 打包脚本成功生成 zip 和 `PACKAGE_MANIFEST.txt`。
- zip 中不存在运行工作区、旧压缩包、缓存、本机绝对路径或禁止文件。
- zip 中包含 README、一键启动入口、源码、测试、示例和开发文档。
- 从 zip 解压出的 README 与当前 Web App/LS-Run 功能语义一致。
