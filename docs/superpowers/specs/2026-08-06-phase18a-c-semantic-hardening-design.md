# Phase 18A–C 语义加固与缺陷修复设计

日期：2026-08-06  
状态：用户已批准方案 2（统一语义修复）。

## 1. 目标

修复第二轮对抗测试确认的 10 个 Phase 18B/18C 缺陷，并通过统一身份、唯一性、空间语义和几何不变量降低后续修复引入关联缺陷的概率。Phase 18A 的源文件、拆分载荷、构件资源计数和兼容接口保持不变。

## 2. 核心语义

### 2.1 空间、结构与切除区

- `spaces` 表示房间、走廊等可使用空气空间，用于空间拓扑、相邻关系和内表面分类。
- `spaces` 不作为 RC 框架梁、柱、板、墙或钢筋的自动切除区。位于房间范围内的轴网梁柱属于合法结构。
- `openings` 表示明确的门、窗或结构洞口，是当前版本唯一自动切除结构实体和钢筋的输入。
- RC 箱体的内部空腔由底板、顶板和外墙六个显式构件的几何形状形成，不依赖 `spaces` 从完整实体中做布尔切除。
- 楼梯洞、电梯井等非门窗结构洞口后续应通过独立的 `structural_voids` 合同扩展；本轮不新增该字段。

### 2.2 多层 RC 连续性

- 建筑最低楼层的柱从基础顶面开始。
- 其余楼层的柱从该楼层 `elevation_m` 开始，与下层楼板在公共坐标面上共享节点。
- 每层柱顶止于该层顶板底面。
- 梁和楼板仍位于对应楼层顶部；共形并集网格负责梁、柱、板交汇区的唯一体积和公共节点。
- `rc_frame` 与 `rc_frame_shear_wall` 的混凝土 Solid 必须保持一个共享节点连通分量。

## 3. Phase 18B 审核与闭包加固

### 3.1 审核身份

完整审核清单必须同时满足：

- 资源映射键等于规范化资源对象 `id`；
- 审核记录 `id` 等于映射键；
- 记录的 `canonical_sha256` 匹配同一对象；
- `resource_kind` 匹配调用边界要求。

任一身份不一致均 fail-closed，不得返回有效审核报告或提升状态。

### 3.2 审核证据

`evidence` 必须是非空列表，且每项必须是 `strip()` 后仍非空的字符串。只含空白的证据无效。

### 3.3 结构目录唯一性

- Set 以 `(set_type, source_id)` 为规范身份，完全重复的身份必须拒绝。
- 耦合关系必须同时保证 `coupling_index` 唯一和完整关系签名唯一；关系签名包含 slave/master kind、ID 和 `sstyp`/`mstyp`。
- 数量正确不能替代身份与关系闭包校验。

## 4. Phase 18C 几何边界与输出清理

### 4.1 包络约束

所有后端在网格生成前验证每个结构成员均完整位于建筑包络内：

- RC 梁深不得使梁底低于所属楼层底面；
- 用户声明的剪力墙边界必须位于建筑包络内；
- 混合结构基础厚度不得超过包络高度；
- 混合结构楼板厚度不得超过所属楼层高度；
- 验证器增加结构节点/单元包络检查，作为后端参数校验之外的第二道防线。

### 4.2 开口唯一性

- 多个不同开口可以连接同一对空间。
- 两个开口可以边界接触，但不允许正体积重叠。
- 重叠检查在合同规范化阶段执行，避免后端分别解释同一几何冲突。

### 4.3 Shell 覆盖判定

- Shell 与 Solid 边界完全重合时，只发布一次流体暴露表面。
- Shell 仅部分被 Solid 覆盖时必须保留为可选表面。
- 判定使用同平面二维矩形覆盖面积/区间并集，不再以 Shell 质心是否落入单个 Solid 面作为替代条件。
- 纯钢框架默认四张屋面 Shell 继续全部发布；混合结构中被混凝土楼板完全覆盖的屋面 Shell 不重复发布。

### 4.4 钢筋节点清理

钢筋线段经过空洞过滤后，只保留仍被 Beam 引用的节点，并按稳定顺序重新编号 Beam 连接。最终 Phase 18C 产物不得包含无单元引用节点。

## 5. 验证策略

每项生产修改必须遵循 RED→GREEN：

1. 为已复现输入编写单一失败测试；
2. 确认测试因对应缺陷失败；
3. 实施最小语义修复；
4. 运行模块测试和交叉测试；
5. 完成后运行 Phase 18A–C 全矩阵及全项目测试。

新增验收覆盖：

- 空白证据、映射键/对象 ID 不一致；
- 重复 Set、重复耦合索引和重复耦合签名；
- 默认 3×3 轴网包含 9 根柱、两个方向各 6 段梁；
- 两层 RC 混凝土为单一连通分量；
- RC/混合结构极端厚度在网格生成前拒绝；
- 验证器能够发现人工构造的包络外结构；
- 部分覆盖 Shell 保留、完全覆盖 Shell 去重；
- 重叠开口拒绝、同空间对不重叠多开口保留；
- 门洞钢筋过滤后孤立节点为零；
- 共形并集网格 100 组随机几何与 50 组顺序反转不变量继续通过。
