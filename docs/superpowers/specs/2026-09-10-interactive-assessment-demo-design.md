# 交互式合成损伤评估演示

用户已批准本方案，要求实施并替换原演示入口。不运行求解器、不接入 DeepSeek、不改变真实项目门禁。

## 已确认范围

固定三层框架建筑及周边地面，柱、梁、楼板、外墙为独立可选构件；可隐藏外墙。按构件显示等级 0—4，未评估、过期或不可评估为灰色；点击模型或明细行显示指标和依据。仅原几何着色，不伪造求解后变形、裂缝或倒塌。

爆源位置（含高度）、当量和数量可修改。首版界面约束：1—5 个源，X/Y -15—15、Z 0—15，当量 1—1000；这是演示和资源限制，不是物理适用范围。修改后旧结果失效，点击评估才计算；相同输入和版本得到相同结果。合成映射不使用爆炸经验公式，不承担实际载荷、传播、遮挡、叠加或毁伤预测。

三种状态：complete 提供完整演示所需的运动学响应；partial 缺可核验的地面身份，建筑可评估而地面不可评估；blocked 缺关键位移，整体不可评估。完整状态仍为研究参考而非 formal；完整并不宣称包含所有材料历史字段。弹性示意材料不伪造塑性损伤量。

## 结构与安全

独立场景/合成适配器通过公开 assess(request, adapter=...) 使用现有真实规则、门禁、报告和证据管线。临时输入显式标 synthetic，不登记求解完成、不写真实项目；TemporaryDirectory 清理自身数据。接口不接受文件路径、项目 ID、规则覆盖或任意场景。

GET /api/damage-assessment/demo/scene 返回模型与默认值；POST /api/damage-assessment/demo/evaluate 只接受 schema_version、mode、sources。沿用 Host/Origin/JSON 检查，限制有限数值、源数量和并发；可选评估依赖缺失返回 503。

独立响应 schema 返回标准评估快照和八项原始工件文本、SHA256。页面报告及 CSV 是明确标记的演示展示副本；完整证据包保留原工件及原始哈希，不能把展示副本与原哈希混用。所有可见结果和导出报告标注“合成数据演示，非真实求解预测”。

原 /damage_assessment_demo.html 与 iframe 入口不变，不引用真实项目 store、不写浏览器持久存储。保留原住宅静态证据文件，仅替换当前演示体验。主项目有大量未提交优化，隔离实现、最小增量接入并保留用户改动。
