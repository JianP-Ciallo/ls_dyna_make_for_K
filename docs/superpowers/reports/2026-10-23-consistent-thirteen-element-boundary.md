# 一致边界流程与13单元静力验收准备

本轮已完成新梁壳父模型的一致边界提取和子域验收流程，并用微型父模型走通。**真实13单元仍需真实父模型100%自重预平衡后才能验收；当前未运行真实整栋或TNT。** 唯一待确认任务见 `artifacts/consistent-boundary-20261023-01/proposal/approval-request.md`。

## 边界定义与物理处理

真实目标仍为原单元154、183、190、191、197、198、199、208、212、420、421、466、467，共9壳4柱。只读FE关联审计得到23个节点：

- 边界11点：187、195、230、231、238、240、248、249、257、528、571。
- 内部12点：201、202、239、246、247、254、255、256、267、268、529、570。

边界按“与子域外单元相连，或属于父模型原真实支座”定义。旧6个边界刚块对应的18节点不是新FE的正确截断集合。旧节点238/248各有两套不相容刚块位姿，不能平均、择一或用零固定代替。

新流程从已通过100%自重的同一个原生父域获取每个共享节点唯一6自由度，保留每个壳层、钢筋和柱纤维的实际原生材料状态。**不重新建立一套独立局部约束、不临时固定内部节点、不重造损伤历史。** 这是静力子域一致性验收，不声称已建立独立动态子模型。

静力荷载保留父模型原节点的精确等效自重和偏心力矩，包括其附属来源，不按局部体积分摊质量。计算子域内力`f_local`、外部单元内力`f_outside`和父节点自重`G`：内部点核验`f_local-G`；边界反力`R=f_local-G`。界面核验`R+f_outside-R_parent_support`；最后一项仅用于父模型真实支座。边界与外部支座分量均随结果记录。

内部节点不存在子域外单元，其父模型物理切线对应的内部自由度主块就是该子域的Dirichlet切线。无需重新固定节点即可检查局部稳定性。真实目标内点为72自由度。

父模型未达100%、实际残差/稳定性不合格、case身份不符或位姿已变化时拒绝发布边界。空、重复、越界和断开的单元集合均拒绝。

## 二阶力矩与原生状态审查

独立审查指出：柱采用PDelta、壳采用初始几何小转动MITC4，不能仅按初始坐标把总力矩残量当成物理失衡。现明确记录原初始坐标总矩，并扣除各PDelta柱的已知几何项：

`M_geom = Σ N * (axis × (u_j-u_i))`

轴力N来自该柱原生`basicForce`，不是从整体残差拟合。父模型和子域均按本混合梁壳离散定义核算，并保存raw总矩、二阶项和修正后总矩。偏心受压单柱专项复现旧量度>1e-5，而正确二阶量度<1e-8；**1e-5门槛未改变**。依据为[OpenSees PDelta实现](https://raw.githubusercontent.com/OpenSees/OpenSees/master/SRC/coordTransformation/PDeltaCrdTransf3d.cpp)的leaning-column抗力项。

另纠正原注释：`ops.initialize()`会执行当前状态的重复零增量提交，不能称为“无材料提交的只读操作”。见[StaticAnalysis原生实现](https://raw.githubusercontent.com/OpenSees/OpenSees/master/SRC/analysis/analysis/StaticAnalysis.cpp)。切换稀疏求解器到FullGeneral读物理切线时，严格检查前后荷载时间及全部可观测场逐项不变；变化立即拒绝。额外用受控应变材料探针比较有无重复初始化提交的后续开裂、卸载和±0.003钢筋屈服路径，柱、壳均一致。这是当前材料/运行时的专项证据，不外推其他本构或任意加载路径。

原生失败步回退后，PlateRebar包装层可能仍缓存上次trial应变；其[官方实现](https://raw.githubusercontent.com/OpenSees/OpenSees/master/SRC/material/nD/PlateRebarMaterial.cpp)的回退只调用底层单轴材料。现先在已回退的节点上更新原生反力/材料读数，再严格核验节点、转角、钢筋、损伤、柱纤维及荷载系数。没有设定或平均节点位移。

## 小例证据

微型父模型为52结构节点、40单元，并非用户630节点、546单元的真实建筑。其13单元子域为4壳9柱，并非真实目标9壳4柱；两者不混称。

微型父域完成全部自重后，13单元同域验收结果：

| 指标 | 实测 |
|---|---|
| 内点实际相对残差 | 9.9718e-12 |
| 界面反力相对残差 | 3.4645e-12 |
| 整体合力相对误差 | 1.8433e-12 |
| 含PDelta修正的合力矩相对误差 | 6.9761e-13 |

| 唯一节点边界与原生材料状态 | 通过，篡改位姿后拒绝过期边界 |

隔离worker在一个微型任务中走通“父模型100%自重→13单元验收”，最终实测约3.25秒，无TNT、无整栋重启。该耗时不能直接作为真实建筑耗时。
