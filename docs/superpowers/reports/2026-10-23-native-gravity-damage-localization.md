## 已修复：静态重力的局部虚功错误

原流程先按板形函数 N_i 分配重量，再把每份重量按原物理点到各节点的偏心距离刚性连接，施加 `(p−x_i)×N_i mg`。这与当前 MITC 壳的独立位移/转角插值不相容：即使重量位于板内，也会额外产生节点弯矩。

一块均布矩形板的虚功反例证实：节点竖向位移为零、仅转角变化时，原代码仍产生不该有的重力虚功。新回归测试修改前失败，修改后通过。修正为按每个真实支承投影位置计算偏心，上下楼层分别投影，保留越界附件及柱轴外钢筋的真实偏心。

例如父节点 285，在不改变竖向力 −23775.43 N 的情况下，原人为 My=13353.77 N·m 被消除。节点 284 靠外墙的真实偏心力矩仍保留，而非把所有节点力矩清零。整个小型来源模型的合力、力矩仍守恒。

实现位置：

- `cpu_response/gravity_mapping.py`：形函数虚功映射及来源指纹。
- `cpu_response/building_mapping.py`：从原始来源积分形成显式重力载荷表，校验合力/力矩。
- `scene_blast/native_reference.py`：使用新载荷表；历史文件仍可按旧方法做诊断回放，并明确标注。

修改模型节点、单元或质量后，旧载荷表会被拒绝，不能静默复用。**这仅修正静态重力；原动态偏心集中质量仍需另行核验，不能据此宣称爆炸动力计算已修好。**

## 尚未修复：原生材料内部的凝聚与导数

保持原材料参数与提交历史，在 7 单元失败试态中发现 PlateFiber 厚度方向应力 σ33 约 −0.20 MPa，未达到其自身 1e-8 Pa 零应力条件，接口仍返回成功。独立 ASD 材料回放与原提交应力的最大误差仅 6.4e-8 Pa。

对同一提交历史、同一面内应变，用有界二分只求厚度应变：4 个试态均在 40–43 次求值内得到根，最终 |σ33| 为 4.55e-9～7.66e-9 Pa。说明这些试态有解，原局部迭代失败不能当作建筑承载力不足。

还发现原生固定前差分会跨越材料分支：其中一个严格根处，原生 D3333 约 0.158 GPa；缩小差分、分别从左右验证后约 29.203 GPa。因此，现有原生矩阵的正定性检查只能作为候选矩阵检查，不能在这一区域代替真实物理导数验证。

官方实现依据：

- [PlateFiber 局部求根](https://github.com/OpenSees/OpenSees/blob/master/SRC/material/nD/PlateFiberMaterial.cpp#L178)：无界 Newton、有限次数退出，失败不充分反馈。
- [ASD 切线差分](https://github.com/OpenSees/OpenSees/blob/master/SRC/material/nD/ASDConcrete3DMaterial.cpp#L1540)：固定扰动，在本次状态跨越分支。
- [NDTest 接口](https://github.com/OpenSees/OpenSees/blob/master/SRC/interpreter/OpenSeesNDTestCommands.cpp#L62)：只能访问注册材料，不能注入壳单元内部复制的积分点材料。

改用割线后某些小路径能前进，但厚度应力与真实切线检查仍不合格，未采纳为修复。纠正重力后的原 7 单元，在相同旧边界延伸下仍于下一步失败，证明不能靠载荷修正宣称材料内核问题消失。

本轮增加了单位权重 Parallel3D 观察包装，保留同一个原材料响应，读取被 PlateFiber 隐藏的六维应力；加入严格 σ33 拒收检查。父报告、实时子域、切线更新后的最终状态、重力保持、回放恢复均检查，不把原生成功码当作物理验收。

真正的后续修复需在原生材料层实现受约束的厚度求根、失败回传及分支一致的导数，并接入独立运行时。当前安装的 Windows Python 模块不能动态替换该材料算子；尚未构建或安装修正版运行时。环境只发现 MinGW C++/Fortran，未发现现成 MSVC、CMake、Conan；[官方 Windows 构建路线](https://opensees.github.io/OpenSeesDocumentation/developer/build.html) 所需工具链尚不齐全。没有把单材料 Python 试验冒充为壳单元内核修复。
