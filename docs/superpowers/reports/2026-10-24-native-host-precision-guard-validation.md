# 材料计算局部64位精度保护与轻量验收

本轮已实现并构建独立运行时，当前 Windows x64 / MinGW GCC 15.2 Release（`-O3 -DNDEBUG`）下的 Python 宿主回归及相关轻量验收通过。没有运行整栋自重、13单元、TNT、全量或其他重型测试；这些结果不能代替后续整栋复验。

## 实现与原门槛

新增 `OPS_ExtendedPrecision.h` 中的局部 RAII 作用域：保存当前线程 x87 控制字，仅把 PC 位改为64位，读回并使用运行期 volatile 低位探针核实有效精度；结束时恢复来时控制字。调用者的舍入方式、异常掩码等控制位以及 MXCSR 控制位保持不变。嵌套作用域恢复各自入口状态，不在 Python 启动阶段永久改动精度。

PlateFiber 公共入口先建立保护，再通过独立的 GCC `noipa` 调用边界进入根搜索。ASD 精度 setter、getter 与增量入口均在保护建立后进入数值体，覆盖厚度高低位组合；Parallel 单子材料精度 setter 同样保护其求值和缓存更新。能力查询现在核实运行期有效精度。保护建立失败会明确拒绝，不把编译期类型位数等同于实际可用精度。

保存的优化汇编证明实际调用顺序为 Scope 构造 → 受保护根搜索 → Scope 析构，异常展开路径也调用析构。诊断增加编译精度、`use_precise`、入口/有效 CW 以及根和括区的低位信息。

最终验收仍直接读取活三维材料返回的真实应力，保持 **|σ33|≤1e-8 Pa**。未插值或清零应力，未更改材料参数、配筋、支承、外部五维应变及其他验收门槛。

## Python 宿主内 RED→GREEN

测试先在未修改的材料对象上得到预期 RED：新检查点在同一 Python 进程来时精度53→64→53时返回 **-1→0→-1**，旧检查点均返回0。然后仅实施上述数值保护，重新构建后得到：

| 保存检查点 | 来时有效精度 | 原生返回 | 真实σ33（Pa） | 返回后控制字 |
| --- | --- | --- | --- | --- |
| 新检查点 | 53 / 64 / 53 | 0 / 0 / 0 | +1.2252512372745716e-12 | 逐次恢复原值 |
| 旧检查点 | 53 / 64 / 53 | 0 / 0 / 0 | -4.191998527816598e-12 | 逐次恢复原值 |

调用之外的运行期低位探针仍为0 / 2^-60 / 0，证明没有以永久更改 Python 宿主精度代替材料内修复。桥接函数没有替材料调用添加 Scope，也不以 MinGW `long double` 跨 ctypes ABI；检查点通过 char*/整数/JSON 接口恢复，并调用与新 pyd 相同构建缓存中的材料实现。

Python 宿主内6项回归通过，覆盖：新旧点、复制/提交/回退/序列化及后续路径、凝聚切线方向、非有限输入拒绝及状态保全、ASD 高低位增量和历史、12种 PC/舍入控制组合、嵌套/异常、4线程各100次精度作用域恢复、实际 pyd 最小板片。线程检查仅证明精度作用域隔离，不宣称既有材料静态工作区已具备线程安全。

实际 pyd 的1m最小板片在明确断言 Python 来时 PC53 的环境下通过：12自由度、全自重因子1，物理残差1.9453171298948883e-11，力误差1.02123055228964e-16，力矩误差1.0212311914215156e-16，真实最大 |σ33|=9.094947017729282e-13 Pa，当前切线正定。该板片是许可的轻量夹具，未组装整栋。

- 相关轻量专项 **35 passed**：冻结材料历史及导数、原生诊断/最小板片、首失败停止控制、单柱自重保持、保存的两板边界回放、开裂及钢筋屈服。未调用带13单元验收的工作入口。
- 原生直接材料回归 **7组通过**：状态、根、壳失败传播、括区、凝聚溢出、无根和序列化。这是指定的材料级入口，不是项目全量测试。
- 最终宿主回归 **6 passed in 3.08s**；合计 **41项 pytest 通过**。相关专项35项耗时7.02s。
- 一次独立只读审查无重要阻塞问题。审查发现的板片组装记录标记已通过独立 RED→GREEN 更正，并补上实际 pyd 板片必须来时 PC53 的前置断言。
- 462个历史证据/源码/旧运行时文件保持散列一致；7个本轮修改的原生文件均保存修改前快照，另有新增精度头文件。此前诊断报告、方案及历史运行时未改写。
- 已删除3个白名单目标、599个中间文件，共 **40.19 MiB**：重复的 staging OpenSeesPy DLL、临时桥接编译对象及其 import library。保留新运行时、已验收的宿主桥接 DLL/原生回归 EXE、源代码、构建配方及全部历史结果。临时 CMake hook 已移除，主体增量构建缓存保留。
