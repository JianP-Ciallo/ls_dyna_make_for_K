# 五类简化场景接管 CPU 默认入口

用户要求将已建的三层住宅、商超、住宅小区、地铁入口及城市街道覆盖原CPU模拟，并完成布局和颜色适配。本轮将 `/cpu-blast` 与尾斜杠入口默认改为新工作台；目录的五类主要链接也统一进入CPU页。几何与轻量动力学沿用此前已验收版本。

本机可见入口：<http://127.0.0.1:8917/cpu-blast>。8917服务为独立只读静态预览，未启动旧工程WebAppServer；正式应用的静态路由映射也已修改，原应用后续启动使用同一页面。预览不提供其他工作台的后台项目API；旧工程记录入口须在原正式应用服务下查看。

布局采用现有工作台浅灰背景、白色面板和青色操作色，统一顶部导航。左侧选择场景与设置爆源，右侧显示三维模型，下方时间轴、计算指标和两条曲线。1920/1536宽屏使用并列布局；1024/768继续保留侧栏；390窄屏视图优先，参数区在下方，曲线均可查看。场景目录同步配色。爆源与损伤的语义颜色保留。

五类场景页内切换，各自保留有效参数及本标签页的未完成草稿；新的 `demo:` 草稿身份不会覆盖旧工程身份。新结果在独立IndexedDB中各保留最近一次，刷新或切回时只恢复匹配场景、参数、几何和帧版本的结果，不自动重算；缓存不可用时仍可计算、回放及下载。初始化缓存读取期间锁定计算及切换；运行中阻止离开或切换，停止后可继续。

原工程HTML、控制器、后端、原生运行时和结果不删除；`/cpu-blast?legacy=1` 保留原工程页面入口。旧 `source` 链接兼容选择新场景，`project_name/scene_id/tnt_scene_id/run_id` 上下文保留到刷新后的旧记录链接。新版不将旧工程结果当成新演示数据，也不自动读取或启动旧求解。旧工程页面顶部CPU项可返回新版。原独立 `/blast_demo.html` URL仍可使用。
