# 梁／分层壳非线性小例验证（2026-10-23）

用户已选择：固定三层建筑改用已有梁／分层壳参考路线；节点按理想整体连接、钢筋充分锚固处理，并标注实际搭接锚固未核实。**本轮实现并验证了隔离的小例内核；真实三层建筑原工况尚未达到重跑条件。没有运行整栋、城市或TNT工况。**

## 已证实的问题与处理

旧刚块模型在197/208接口使用统一0.5%钢筋率，界面钢筋总面积180mm²、层位±51.96mm；参考两侧X向钢筋分别约403.75/742.48mm²，层位分别−42/+6.0003mm和−42/+42mm。面积、层位及膜弯耦合都不能由一个统一截面代表。原节点质量等分给独立刚块虽保全局质量和矩，却不保相同的局部承载运动学。

新小例保留参考模型的共享节点、原钢筋面积与层位、柔性壳、偏心质量点及其原FE主节点约束。新增质量来源账本，记录来源质量、一阶/二阶矩、路由及各主节点分配量；不再将参考节点质量等分给独立宏块。原K和现有生产入口保持原状。旧失败现场和旧求解器作为诊断对照保留。

## 非线性内核的具体范围

- 柱：原纤维位置和混凝土钢筋等面积置换，`Concrete02`、`Steel01`加`MinMax`，三点Lobatto等价自定义积分，按积分权重确定拉伸断裂能特征长度；PDelta变换，保留原几何中面，使用`-noCentroid`避免不对称配筋被自动重新居中。
- 板：原始分层和方向；`ASDConcrete3D → PlateFiber → LayeredShell/ShellMITC4`，钢筋读取原生分层材料实际应力，不能用`Es×应变`代替屈服后的应力。
- 材料：`fc=30MPa`、`ft=2MPa`、`fy=400MPa`、`Gf=200N/m`及钢筋极限总应变0.05。恢复参考文件`Ec=30GPa、Es=210GPa`；旧宏块代理Es为200GPa，此处是恢复参考值，不能声称所有旧代理参数完全未变。
- 拉伸律总曲线面积乘特征长度严格等于Gf；不解析既定断裂能的过大网格直接拒绝。壳特征长度采用面积平方根，尚未完成网格/裂缝方向客观性验证。没有黏性、IMPL-EX或人为残余拉力。
- 压缩峰值应变约0.002、零应力终点0.006为明确的无约束混凝土假设，未标定实际构造。柱剪切/扭转及大转动壳、碎片接触、钢筋黏结滑移和倒塌尚不在此小例内核的验收范围。
- “理想整体节点、充分锚固；实物搭接锚固未核实”及上述局限随模型和结果/诊断一起保存。

[ASDConcrete3D官方文档](https://opensees.github.io/OpenSeesDocumentation/user/manual/material/ndMaterials/ASDConcrete3D.html)支持原生损伤响应与所用材料选项；[Concrete02官方文档](https://opensees.github.io/OpenSeesDocumentation/user/manual/material/uniaxialMaterials/Concrete02.html)给出初始刚度和拉伸软化参数定义。这些资料支持实现选择，不能替代本项目的模型标定。

## 自重、物理门槛与回滚

重力保持`9.80665m/s²`，对参考偏心质量点施加重力并经约束转置形成主节点力和偏心力矩。底部固定质量仍计入固定端受力账本。没有跳过重力、修改强度或为通过验收添加刚度。

最终门槛为：独立装配每个梁/壳的原生内力，核验自由节点实际相对残差≤`1e-5`，同时核验整体反力与力矩；当前物理切线的对称、对角尺度化矩阵减去`1e-9 I`须通过Cholesky。力矩残差按各节点局部特征长度缩放，并单独输出力/力矩残差。**FE节点与旧宏块的自由度及长度尺度不同，不能仅因门槛数字相同就比较两次残差大小。**

原生迭代停止条件采用本级自由重力范数的`1e-6`作为有一数量级余量的内部条件；它不能替代以上独立`1e-5`门槛。`printA`会重组切线，另做零荷载增量平衡更新；不平移、不修补物理矩阵。[原生实现](https://github.com/OpenSees/OpenSees/blob/master/SRC/interpreter/OpenSeesCommands.cpp)可核对`OPS_printA`的`formTangent`调用。

Windows原生FileDatastore恢复探针出现`Domain::recv ... failed to recv the initial ID`，未将其当作有效检查点。本小例改用重建模型、只重放已接受增量恢复历史，并核验位移、所有钢筋应力/应变、壳混凝土损伤、柱原生纤维响应及荷载系数。此做法有严格128结构节点/128单元/768质量点规模限制，不能据此声称整栋性能已验证。

拒绝试算、超时和异常保存诊断；审查发现的“稳定性超时绕过回滚”及“再次恢复失败时沿用旧True标志”均经先红后绿修复。原生`analyze`返回非零时会自动回退，诊断中的域字段明确标为**返回后的状态**，不冒充已无法读取的最后一次未提交牛顿迭代场。非有限值在JSON中记为null并列出路径，不置零。

## 实测结果

下表全部是专项小例。**52节点、40单元的微型柱板fixture不是用户630节点、546单元的真实三层建筑。** 时间为本机本轮墙钟实测，不用于推算整栋耗时。

| 核验 | 本轮结果 |
|---|---|
| 微型柱板100%自重 | 通过，约3.609s；实际相对残差`1.6533e-11`；力/力矩分量分别`1.5991e-11`、`4.1984e-12`；切线正定 |
| 微型柱板整体平衡 | 合力相对误差`1.2006e-12`，合力矩相对误差`6.1703e-7`，均小于`1e-5` |
| 单柱自重后20ms无爆炸保持 | 20步，无阻尼掩盖；最大位移漂移约`2.19e-16m`，钢筋应力漂移0Pa |
| 材料拉伸/钢筋屈服 | 原生壳混凝土损伤可读；钢筋应力达到400MPa屈服平台；Gf积分及过大网格拒绝验证通过 |
| 原失败197/208双壳 | 原参考两侧截面、共用接口节点、记录外端非零位移/转角，已接受与被拒两套边界分别完成局部平衡；约0.2s/例，实际残差约`1e-14`量级 |
| 超载、断开 | 仍拒绝；超载约0.047s，以物理门槛失败退出，恢复到已接受状态；未解释为求解成功 |
| 超时、第二次恢复失败、原生异常、非有限场 | 故障注入先红后绿；保存诊断并正确标识是否恢复 |

双壳试验没有施加自重或TNT，原生本构历史从零开始；旧刚块损伤历史不能直接改名为原生材料历史。它验证原失败位置的截面和边界传力，**不证明完整13单元子模型或整栋100%自重通过**。

## 完整13单元边界仍未验收

13体旧现场的恢复力、截断力矩和非零边界位姿已完整保留；旧模型仍复现同类线搜索失败，作为负对照。转成共享FE节点后，原边界迹不再相容：

| 参考节点 | 旧边界单元 | 已接受现场的位移差 |
|---|---|---|
| 238 | 183/191 | `8.879822e-6m` |
| 248 | 191/199 | `1.205449e-5m` |

相邻刚块允许独立转动/开裂，而一个整体壳节点只有一套位姿。这是两种运动学不一致的具体证据，不能用平均、择一或零固定后宣称原边界已验证。程序输出拒迁审计；完整子模型和整栋承载路径仍待新FE整体预平衡得到一致边界后验收。

因此本轮**不申请也不运行原10kg TNT工况**。下一阶段需先补齐生产规模梁壳装配/诊断与一致边界流程；真实整栋预平衡属于受控重型运行，必须另列范围、预计耗时并取得当次明确同意。TNT瞬态、失效/倒塌和工作台结果接入仍未验收。
