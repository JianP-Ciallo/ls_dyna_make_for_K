# 碎片互撞与堆积实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在当前五场景演示中加入双向碎片碰撞、摩擦与落地堆积，保持现有裂缝演化和全部历史证据。

**Architecture:** 使用脱离三角片的实际厚度三棱柱和脱落构件长方体作为接触形状；空间分桶筛选候选、凸体分离轴及平移扫掠检测接触。对双方施加质量加权分离和带角动量的碰撞/摩擦速度响应，交替处理环境接触维持堆积。F64 原状态通过稳定代理接口直接更新，保留现有 Worker/回放几何协议。增强结果升级 @5，保留 @4 缓存；对比模式 @2 不改。

**Tech Stack:** 原生 JavaScript，无新依赖；Node 小模型、相关 pytest、Edge 五场景与模式专项。

**Spec:** 用户本次明确要求继续加入碎片互撞与落地堆积，暂不做复杂钢筋本构。沿用此前已确定的简化演示路线及自主实施方式，不新增设计确认环节。

## Global Constraints

- 原地保留全部已有修改与历史结果，不提交/合并，不清理旧证据。
- 不改几何、材料承载参数、配筋、支承；不引入复杂钢筋本构。
- 不启动原生整栋、自重、13 单元、TNT、全量或其他重型流程；仅简化浏览器演示及其专项。
- 不伪造堆积几何，不把落地碎片直接变成无限质量地板，不为性能静默跳过碰撞。
- 容量保护若触发须显式停止并保存失败，不将有限/未执行写成通过。

## Review Focus

1. 同板断开的碎片仍应互撞，尚未断键的一环邻接应避免自挤；不能仅按 bodyId 排除碰撞。
2. 先完成所有构件积分与内部约束，再统一接触，碰撞速度不能被节点速度重建覆盖。
3. 双向有限质量和角速度响应须避免增加碰撞能量，落地底层不得向下穿过地板。
4. 薄片迎面高速交错及连续落片堆积；同时验证零输入、不接触的自由运动与斜置三角片。
5. 旧 @4 结果/缓存、对比模式以及已保存数据不可被覆盖，新版刷新回放须一致。

## 取舍记录

- 采用实际三角片厚度代理而非球形替代，避免薄片形成夸大的球状碎石堆；不加入工程材料模型。
- 接触形状的惯量按几何体积分布近似，均一相对密度仅用于演示质量比，不新增工程材料标定。
- 180 Hz 积分、60 Hz 接触，保存上次接触完成后的实际位置作跨步扫掠；不是按距离/数量静默漏算接触。默认 2 次交替迭代，保留小模型的厚度与稳定性门槛。
- 健康接缝按 bond 端点建立局部焊接类，接触后交替投影坐标/速度，避免人为数值断缝；只有实际有支承并持续 12 次低速更新才计入静止。
- 候选/分桶/原始访问与统一单步计时都有限额，超额明确停止。代理历史用对象键，避免形状显示 ID 重号串用。
- 参考 Müller 等 [Detailed Rigid Body Simulation with Extended Position Based Dynamics](https://matthias-research.github.io/pages/publications/PBDBodies.pdf) 的双向接触点速度及摩擦思路；本轮不宣称完整 XPBD 实现。

## 最终实现补充

低速三角片使用带厚度最近特征接触，高速/中面交叉与箱体保留 SAT/CCD；加入可沿接触图唤醒的受支承休眠。用户另明确批准住宅小区180秒一轮，174.75秒内通过，详见报告。
