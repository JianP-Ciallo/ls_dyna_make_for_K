# Blast Modeling Agent Runtime Execution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Phase C controlled modeling runtime: a crash-safe, approval-gated, localhost-only agentd that creates at most one deterministic controlled ALE project per action, validates it, recovers safely, and remains invisible when the Agent feature flag is off.

**Architecture:** The existing MCP server, 44-tool registry, Web routes, project format, and project transaction remain the deterministic legacy kernel. A separate lsprepost_mcp.agent control plane owns the state machine, SQLite single-writer ledger, policy, approvals, action receipts, recovery, and audit projections; the existing Web server reaches it only through an explicit localhost sidecar proxy. Modeling writes are performed by a closed wrapper around generate_ale_blast_demo with a stable action ID, an action-derived target name, and forced if_exists=error.

**Tech Stack:** Python standard library, dataclasses, json, hashlib, sqlite3 with WAL and Backup API, http.server, http.client, queue, threading, subprocess anonymous pipes, unittest, PowerShell and cmd launchers, plain HTML/CSS/JavaScript.

**Spec:** docs/superpowers/specs/2026-08-15-blast-modeling-agentization-design.md

## Global Constraints

- Treat ModelingCaseSpec schema_version as exactly blast_modeling_case@1 and the MVP profile as exactly controlled_ale_blast@1.
- Consume the Phase A/B interfaces canonical_json_bytes(value), canonical_sha256(value), AdapterCompilation.domain_arguments, and bind_dry_run(compilation, validation_project_name). Phase C adds bind_create(compilation, target_project_name) beside bind_dry_run in lsprepost_mcp.agent.adapters.base; do not create a second canonicalization or adapter-binding implementation.
- AdapterCompilation.domain_arguments must never contain project_name, dry_run, if_exists, force, manual_ack, allow_external, executable paths, or resource-limit policy fields.
- Preserve the current 44 MCP tool names, order, descriptions, complete input schemas, defaults, JSON-RPC behavior, and content envelope. Do not modify lsprepost_mcp/tools.py or lsprepost_mcp/server.py.
- Preserve the existing lsprepost_mcp/project_store.py public behavior and old project format. Continue to use ProjectLock, atomic project commit, model.k, model.json@0.2.0, checks.json, and open_model.cfile.
- Do not add action_id to ale_blast_demo_input_schema(). action_id is Agent ledger data, not a legacy tool argument.
- Every Agent project write must call the existing controlled generator with dry_run=False and if_exists=error. The Agent path must never call overwrite, archive_then_write, or versioned.
- tool_validate_model is not read-only because it rewrites checks.json. Agentd may call it only as the internal post-write validation step of the same approved modeling action, using that action's persisted approval and server-bound target; it must update the same action receipt and audit events without creating a second approval. Do not change the legacy handler, schema, return value, or public TOOLS registration.
- A repair must create a new plan revision, a new action ID, and a new deterministic project name. It must not modify or replace the earlier project.
- agentd must bind only 127.0.0.1, remain a separate process from both the stdio MCP server and Web server, and act as the state single writer.
- The agentd internal secret must be generated by agentd and transferred to the Web parent over an anonymous pipe handshake. It must not appear in argv, environment variables, files, SQLite, logs, browser responses, browser storage, or object repr output.
- Browser approval must use an HttpOnly, SameSite=Strict session plus an action-specific, one-time nonce bound to action_digest, session fingerprint, run ID, target revision, expiry, and consumed state.
- L2 policy is fixed: R0 and R1 may execute and be audited; R2 may execute only for the approved current plan action; R3 must return a legacy handoff without calling a handler even when an approval is supplied; R4 must return policy_denied without calling a handler.
- The model must not see actual write handlers, recovery probes, approval commands, the internal secret, or approval-policy fields.
- The first plan may contain at most 8 steps, one run may contain at most 3 repair iterations, one model decision may propose only one primary action, and parallel tool calls are forbidden.
- workspace/agent/agent.sqlite3 is the transactional fact source. run.json, events.jsonl, and revision snapshots are replaceable projections and never a second mutable source.
- Phase C audit output is limited to run.json, events.jsonl, and snapshots/revision-<N>.json. Do not create or reserve exports/agent_delivery@1; Phase D owns that package.
- knowledge_snapshot_hash is the only action/plan digest key for the knowledge snapshot and its value is always a lowercase 64-character SHA-256. Before Phase D supplies a snapshot, Phase C uses canonical_sha256({"schema_version": "knowledge_snapshot_absence@1"}); it never uses a text sentinel or an alternate key.
- Enabling the feature must not create agent.sqlite3 until the first fully validated create_run request. Capabilities, old pages, old APIs, and invalid Agent requests must not create the database.
- LSPP_AGENT_ENABLED is off by default. When off, no Agent API capability response, Agent entry page, database creation, DeepSeek request, or sidecar startup is allowed.
- Do not import Phase 18 private functions or unpublished refined-blast objects. The vertical slice uses the public controlled ALE adapter and the public generate_ale_blast_demo path only.
- Do not store API keys, raw session secrets, unrelated documents, full private prompts, provider reasoning_content, or hidden chain-of-thought in SQLite, events, logs, or audit files.
- Completion must preserve four independent facts: software_validated, solver_executed, result_checked, and engineering_reviewed. The Phase C happy path sets only software_validated=true.
- Required CI is offline and uses fake/replay providers. Real DeepSeek calls remain an optional canary and are not part of this plan's required commands.
- Every test command in this plan invokes python -m unittest; no alternate test runner is required.

            created_at=now,
            updated_at=now,
            terminal_at=None,
        )

        return replace(self, **changes)

    def to_dict(self) -> JSONDict:
        value = asdict(self)
        value["status"] = self.status.value
        value["project_refs"] = [dict(item) for item in self.project_refs]
        return value

    @classmethod
    def from_dict(cls, raw: Mapping[str, object]) -> "AgentRunState":
        value = dict(raw)
        value["status"] = RunStatus(str(value["status"]))
        value["plan"] = (
            None if value["plan"] is None else AgentPlan.from_dict(value["plan"])
        )
        value["project_refs"] = tuple(dict(item) for item in value["project_refs"])
        return cls(**value)


def transition_state(
    state: AgentRunState,
    *,
    expected_revision: int,
    target: RunStatus,
    now: str,
    patch: Mapping[str, object] | None = None,
    l2_mode: bool = True,
) -> AgentRunState:
    if state.revision != expected_revision:
        raise ValueError(
            f"stale_state: expected revision {expected_revision}, current {state.revision}"
        )
    if l2_mode and target is RunStatus.WAITING_EXTERNAL_RESULT:
        raise ValueError("L2 does not enter waiting_external_result")
    if target not in LEGAL_TRANSITIONS[state.status]:
        label = "terminal state" if not LEGAL_TRANSITIONS[state.status] else "illegal transition"
        raise ValueError(f"{label}: {state.status.value} -> {target.value}")
    changes = dict(patch or {})
    changes.update({
        "status": target,
        "revision": state.revision + 1,
        "updated_at": now,
        "terminal_at": now if target in {
            RunStatus.COMPLETED, RunStatus.FAILED, RunStatus.CANCELLED
        } else None,
    })
    return replace(state, **changes)

class EventPayloadRegistry:
    def __init__(self) -> None:
        self._keys: dict[tuple[str, str], frozenset[str]] = {}

    def register(
        self,
        event_type: str,
        payload_schema_version: str,
        allowed_keys: frozenset[str],
    ) -> None:
        key = (event_type, payload_schema_version)
        if key in self._keys:
            raise ValueError(f"event payload validator already registered: {key}")
        self._keys[key] = allowed_keys

    def knows(self, event_type: str, payload_schema_version: str) -> bool:
        return (event_type, payload_schema_version) in self._keys

    def validate(
        self,
        event_type: str,
        payload_schema_version: str,
        payload: Mapping[str, object],
    ) -> None:
        key = (event_type, payload_schema_version)
        allowed = self._keys.get(key)
        if allowed is None:
            raise ValueError(f"unregistered event payload: {key}")
        unknown = sorted(set(payload) - set(allowed))
        if unknown:
            raise ValueError(f"unsupported event payload fields: {', '.join(unknown)}")

class AgentStore:
    def __init__(self, path: Path, connection: sqlite3.Connection) -> None:
        self.path = path
        self.connection = connection

    @contextmanager
    def transaction(self, *, immediate: bool = False) -> Iterator[sqlite3.Connection]:
        self.connection.execute("BEGIN IMMEDIATE" if immediate else "BEGIN")
        try:
            yield self.connection
            self.connection.commit()
        except BaseException:
            self.connection.rollback()
            raise

    def cas_snapshot(
        self,
        run_id: str,
        expected_revision: int,
        next_state: AgentRunState,
    ) -> None:
        cursor = self.connection.execute(
            """
            UPDATE agent_runs
               SET state=?, revision=?, snapshot_json=?, updated_at=?, terminal_at=?
             WHERE run_id=? AND revision=?
            """,
            (
                next_state.status.value,
                next_state.revision,
                json.dumps(next_state.to_dict(), ensure_ascii=False, sort_keys=True),
                next_state.updated_at,
                next_state.terminal_at,
                run_id,
                expected_revision,
            ),
        )
        if cursor.rowcount != 1:
            row = self.connection.execute(
                "SELECT revision FROM agent_runs WHERE run_id=?",
                (run_id,),
            ).fetchone()
            raise StaleStateError(-1 if row is None else int(row[0]))

    def claim_lease(
        self,
        run_id: str,
        owner_id: str,
        now_epoch_s: float,
        ttl_s: float,
    ) -> bool:
        with self.transaction(immediate=True):
            cursor = self.connection.execute(
                """
                UPDATE agent_runs
                   SET lease_owner=?, lease_expires_at=?
                 WHERE run_id=?
                   AND (
                       lease_owner IS NULL
                       OR lease_owner=?
                       OR lease_expires_at < ?
                   )
                """,
                (owner_id, now_epoch_s + ttl_s, run_id, owner_id, now_epoch_s),
            )
            return cursor.rowcount == 1

    def backup_to(self, path: Path) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        target = sqlite3.connect(path)
        try:
            self.connection.backup(target)
        finally:
            target.close()

    def schema_version(self) -> int:
        return int(self.connection.execute("PRAGMA user_version").fetchone()[0])

    def close(self) -> None:
        self.connection.close()


def open_agent_store(path: Path) -> AgentStore:
    path.parent.mkdir(parents=True, exist_ok=True)
    connection = sqlite3.connect(
        path,
        timeout=5.0,
        isolation_level=None,
        check_same_thread=False,
    )
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA foreign_keys=ON")
    connection.execute("PRAGMA journal_mode=WAL")
    connection.execute("PRAGMA synchronous=FULL")
    connection.execute("PRAGMA busy_timeout=5000")
    migration_time = datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")
    migrate(connection, migration_time)
    # check_same_thread=False is safe only because AgentCommandQueue serializes access.
    return AgentStore(path, connection)

class PolicyEngine:
    POLICY_OWNED_FIELDS = frozenset({
        "project_name",
        "dry_run",
        "if_exists",
        "force",
        "manual_ack",
        "allow_external",
    })

    def evaluate(
        self,
        descriptor: AgentExecutionDescriptor,
        arguments: Mapping[str, object],
        approval: Mapping[str, object] | None,
        *,
        action_digest: str,
        expected_revision: int,
    ) -> PolicyDecision:
        if self.POLICY_OWNED_FIELDS.intersection(arguments):
            return PolicyDecision(False, False, "policy_owned_argument")
        if descriptor.risk is RiskLevel.R4 or descriptor.effect is EffectClass.FORBIDDEN:
            return PolicyDecision(False, False, "policy_denied")

            descriptor.risk is RiskLevel.R3
            or descriptor.effect in {
                EffectClass.IRREVERSIBLE_WRITE,
                EffectClass.EXTERNAL_EFFECT,
            }
        ):
            return PolicyDecision(False, False, "legacy_handoff_required")
        if descriptor.risk is RiskLevel.R2:
            if approval is None or approval.get("decision") != "approved":
                return PolicyDecision(False, True, "approval_required")
            digest_matches = hmac.compare_digest(
                str(approval.get("action_digest", "")),
                action_digest,
            )
            revision_matches = approval.get("target_revision") == expected_revision
            if not digest_matches or not revision_matches:
                return PolicyDecision(False, True, "approval_mismatch")
            return PolicyDecision(True, True, None)
        return PolicyDecision(True, False, None)
~~~

class AgentToolGateway:
    def __init__(
        self,
        *,
        descriptors,
        handlers,
        policy: PolicyEngine,
        postwrite_validator=None,
    ) -> None:
        validate_complete_descriptor_registry(descriptors, handlers)
        self._descriptors = dict(descriptors)
        self._handlers = dict(handlers)
        self._policy = policy
        self._postwrite_validator = postwrite_validator

    def model_visible_tool_names(self) -> tuple[str, ...]:
        return tuple(sorted(self._descriptors))

    def execute(self, request: GatewayRequest) -> GatewayResult:
        descriptor = self._descriptors.get(request.tool_name)
        if descriptor is None:
            return denied_result("unknown_agent_tool")
        decision = self._policy.evaluate(
            descriptor,
            request.arguments,
            request.approval,
            action_digest=request.action_digest,
            expected_revision=request.expected_revision,
        )
        if not decision.allowed:
            return denied_result(decision.error_code or "policy_denied")
        try:
            value = self._handlers[request.tool_name](dict(request.arguments))
            return GatewayResult(True, normalize_tool_result(value), None)
        except Exception as exc:
            return GatewayResult(False, None, normalize_tool_error(exc))

    def execute_postwrite_validation(
        self,
        action: "AgentActionRow",
    ) -> GatewayResult:
        if (
            self._postwrite_validator is None
            or action.status != "completed"
            or action.approval is None
        ):
            return denied_result("approved_action_required")
        descriptor = AgentExecutionDescriptor.postwrite_validation()
        decision = self._policy.evaluate(
            descriptor,
            {},
            action.approval,
            action_digest=action.action_digest,
            expected_revision=int(action.prepared["target_revision"]),
        )
        if not decision.allowed:
            return denied_result(decision.error_code or "policy_denied")
        try:
            value = self._postwrite_validator({
                "project_name": action.target_name,
            })
            return GatewayResult(True, normalize_tool_result(value), None)
        except Exception as exc:
            return GatewayResult(False, None, normalize_tool_error(exc))

~~~python
from __future__ import annotations

import hashlib
import json
from dataclasses import dataclass
from pathlib import Path
from typing import Callable, Mapping

from .hashing import canonical_sha256


@dataclass(frozen=True)
class RecoveryProbe:
    outcome: str
    evidence: Mapping[str, object]


def sha256_file(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b""):
            digest.update(block)
    return digest.hexdigest()


def probe_controlled_ale_action(
    prepared,
    *,
    project_root: Path,
    validator: Callable[[dict[str, object]], Mapping[str, object]],
) -> RecoveryProbe:
    target = project_root / prepared.target_relative_path
    if not target.exists():
        return RecoveryProbe("absent", {"target_relative_path": prepared.target_relative_path})
    try:
        model = json.loads((target / "model.json").read_text(encoding="utf-8"))
        actual_spec_hash = canonical_sha256(model["spec"])
        actual_model_k_sha256 = sha256_file(target / "model.k")
        if actual_spec_hash != prepared.expected_spec_hash:
            return RecoveryProbe("conflict", {
                "field": "model.json.spec",
                "expected": prepared.expected_spec_hash,
                "actual": actual_spec_hash,
            })
        if actual_model_k_sha256 != prepared.expected_model_k_sha256:
            return RecoveryProbe("conflict", {
                "field": "model.k",
                "expected": prepared.expected_model_k_sha256,
                "actual": actual_model_k_sha256,
            })
        validation = validator({"project_name": prepared.target_name})
        checks_fingerprint = canonical_sha256(validation)
        evidence = {
            "target_relative_path": prepared.target_relative_path,
            "actual_spec_hash": actual_spec_hash,
            "actual_model_k_sha256": actual_model_k_sha256,
            "actual_model_json_sha256": sha256_file(target / "model.json"),
            "checks_fingerprint": checks_fingerprint,
            "checks_ok": bool(validation["ok"]),
            "readiness": dict(validation["readiness"]),
        }
        return RecoveryProbe(
            "matching" if validation["ok"] else "evidence_invalid",
            evidence,
        )
    except (OSError, UnicodeError, json.JSONDecodeError, KeyError, TypeError) as exc:
        return RecoveryProbe("unknown", {
            "error_type": type(exc).__name__,
            "target_relative_path": prepared.target_relative_path,
        })
~~~

The prepared row deliberately stores only `expected_spec_hash` and `expected_model_k_sha256`. Recovery recalculates the canonical `model.json.spec` hash and the validation/checks fingerprint. The full `model.json` hash and checks fingerprint are actual receipt evidence produced after creation or recovery; neither is an expected prepared precondition.

~~~python
class FaultInjector:
    VALID_POINTS = frozenset({
        "after_action_prepared",
        "before_executor",
        "after_project_commit_before_receipt",
        "before_complete_transaction_commit",
        "after_complete_transaction_commit",
    })

    def __init__(self, armed_point: str | None = None) -> None:
        if armed_point is not None and armed_point not in self.VALID_POINTS:
            raise ValueError("unknown fault point")
        self._armed_point = armed_point

    def hit(self, point: str) -> None:
        if point not in self.VALID_POINTS:
            raise ValueError("unknown fault point")
        if point == self._armed_point:
            raise InjectedCrash(point)


class RecoveryCoordinator:
    def __init__(self, dependencies) -> None:
        self._store = dependencies.store
        self._project_root = dependencies.project_root
        self._validator = dependencies.validator
        self._clock = dependencies.clock

    def recover_startup(self) -> RecoveryReport:
        outcomes: dict[str, str] = {}
        for action in self._store.list_recoverable_actions():
            prepared = PreparedAction.from_dict(action.prepared)
            probe = probe_controlled_ale_action(
                prepared,
                project_root=self._project_root,
                validator=self._validator,
            )
            if probe.outcome == "absent":
                self._store.mark_action_prepared(action.action_id)
                outcomes[action.action_id] = "resumable"
            elif probe.outcome == "matching":
                receipt = receipt_from_recovery_evidence(
                    prepared,
                    probe.evidence,
                    completed_at=self._clock(),
                )
                self._store.complete_recovered_action(action.action_id, receipt)
                outcomes[action.action_id] = "receipt_rebuilt"
            else:
                self._store.pause_for_recovery(
                    action.run_id,
                    action.action_id,
                    probe.outcome,
                    probe.evidence,
                )
                outcomes[action.action_id] = probe.outcome
        return RecoveryReport(outcomes)
~~~

Wire `FaultInjector.hit` at the five exact boundaries. A crash before the executor leaves `prepared`; a crash after the executor begins first marks `uncertain`; completion writes receipt, action status, run CAS, and events in one transaction. Repeated recovery is idempotent by `action_id` and event uniqueness.

class AuditExportManifest:

    run_id: str
    revisions: tuple[int, ...]
    event_count: int
    files: tuple[str, ...]

    def to_dict(self) -> dict[str, object]:

            "run_id": self.run_id,
            "revisions": list(self.revisions),
            "event_count": self.event_count,

    def __init__(self, store) -> None:
        self._store = store

    def export_run(self, run_id: str, destination: Path) -> AuditExportManifest:
        run = self._store.get_run(run_id)
        events = tuple(self._store.list_events(run_id, after_sequence=0))

        snapshot_dir = destination / "snapshots"

        for snapshot in snapshots:

        files = (
            "run.json",
            "events.jsonl",
            *(f"snapshots/revision-{item.revision}.json" for item in snapshots),
        )
        return AuditExportManifest(
            schema_version="agent_audit_export@1",
            run_id=run_id,
            revisions=tuple(item.revision for item in snapshots),
            event_count=len(events),
            files=files,
        )

from __future__ import annotations

import queue
import threading
from concurrent.futures import Future
from dataclasses import dataclass
from typing import Callable


@dataclass(frozen=True)
class _QueuedCommand:
    operation: Callable[..., object]
    args: tuple[object, ...]
    kwargs: dict[str, object]
    future: Future[object]


class AgentCommandQueue:
    def __init__(self) -> None:
        self._queue: queue.Queue[_QueuedCommand | None] = queue.Queue()
        self._thread = threading.Thread(
            target=self._run,
            name="agentd-writer",
            daemon=True,
        )
        self._thread.start()

    def submit(self, operation, *args, **kwargs):
        future: Future[object] = Future()
        self._queue.put(_QueuedCommand(operation, args, dict(kwargs), future))
        return future.result()

    def _run(self) -> None:
        while True:
            command = self._queue.get()
            if command is None:
                return
            try:
                command.future.set_result(
                    command.operation(*command.args, **command.kwargs)
                )
            except BaseException as exc:
                command.future.set_exception(exc)

    def close(self) -> None:
        self._queue.put(None)
        self._thread.join(timeout=5.0)
        if self._thread.is_alive():
            raise RuntimeError("agentd writer did not stop")

    def issue(self, now: float) -> BrowserSession:
        session_id = secrets.token_urlsafe(32)
        session = BrowserSession(
            session_id=session_id,
            csrf_token=secrets.token_urlsafe(32),
            fingerprint=hashlib.sha256(session_id.encode("utf-8")).hexdigest(),
            expires_at=now + 8 * 60 * 60,
        )
        self._sessions[session_id] = session
        return session

    def validate(self, cookie_value: str, csrf_token: str, now: float) -> BrowserSession:
        session = self._sessions.get(cookie_value)
        if session is None or session.expires_at < now:
            raise WebAgentError(403, "session_invalid")
