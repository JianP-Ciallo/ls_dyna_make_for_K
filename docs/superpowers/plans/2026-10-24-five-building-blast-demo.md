# 五种建筑分别构建与独立爆炸演示

用户要求按照已可运行的简化演示方法，再建四栋建筑。用户明确：各自构建，不放在一起。沿用用户此前直接实施的授权，不恢复K模型、自重求解或原生重型测试。保留现有三层楼入口；另外四栋各有独立URL、参数配置及Worker结果，一页只显示一栋。原型仍为有体积构件的简化动力学。

具体类型由实现方先选2层住宅、5层公寓、4层办公楼及8层塔楼，尺寸、颜色及阳台外形区分。采用参数化建筑生成器，每栋独立生成有体积的楼板、墙、柱、楼梯和屋面。相同构件失效和运动计算用于每栋，不强制相同破坏结果。没有构件之间的接触碰撞或爆炸流场计算。

实现顺序：

1. 保留共享源文件的本轮前快照。增加四种新几何、支承索引有效性、各自爆源禁入、各自爆炸与零作用静止、距离响应专项，先记录失败。
2. 参数化既有建筑生成器，提供明确预设ID，保留无参数原三层接口及原参数存储键。Worker根据独立建筑ID生成同一几何，配置校验拒绝未知ID。
3. 共享视图根据单栋尺寸调整相机、地台和阴影。页面通过URL打开所选建筑，另设目录入口；每栋在独立标签页打开，参数存储键和导出文件按建筑区分，不复用另一栋结果。
4. 运行原单栋专项、四种新建筑专项及静态打包专项；以Edge专项检查各自真实Worker、回放、模型身份、配置隔离及导出，做一次必要的独立只读审查。
5. 用关闭窗口图形加速的可见Edge打开建筑目录和一栋新建筑，核对实际桌面并播放强烈爆炸。保存截图、结果和报告；保留旧历史，仅清理本轮可重建临时文件。

本轮仅各栋简化演示的短时计算与相关轻量专项，不运行旧整栋自重、13单元、原生TNT、全量或其他重型案例；不提交、合并或清理整个工作区。
