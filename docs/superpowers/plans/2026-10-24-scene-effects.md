# 其他场景破坏效果与三层演示统一计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 商超、小区、地铁、街道获得同样清晰的弯曲、碎裂、互撞与堆积观察入口，保留原设计和历史。

**Architecture:** 动力学仍用 @5，不调整材料或支承。统一增强模式入口与旧页模式选择；新增纯函数场景目标/相机配置，前台提供“应用目标演示／聚焦破坏／观察碎片”，保留全景及旧参数。城市新建草稿推荐商超正面空地，已有草稿不静默覆盖；其他原场景保持原示例载荷。保存结果按实际受损对象聚焦回放，减少烟尘遮挡。

**Tech Stack:** 原生 JavaScript / Three.js；Node 专项、pytest 包装、Edge 保存结果回放与短程城市目标样例。

**Spec:** 用户要求优化其他场景以获得三层建筑同样效果；沿用简化演示、自主实施方式，不新增设计确认。

## Global Constraints

- 不改变几何、承载参数、配筋、支承、损伤门槛或 @5 求解实现。
- 保留全部已有修改、旧草稿和历史结果，不提交或清理旧证据。
- 不重跑住宅小区长测；用上轮真实 6 秒保存结果回放验证视图。长时/重型验收须重新说明范围与时间并取得当次明确同意。
- 不自动计算或强制覆盖手工爆点；目标切换/聚焦仅改变视图，应用示例需用户明确点击。

## Review Focus

1. 旧独立页面和旧草稿中的 components，不应被误称已进入增强计算；清晰模式选择且旧参数仍保留。
2. 城市多实例必须聚焦实际建筑，推荐爆点合法且在正面空地，不靠提高当量或削弱材料制造效果。
3. 相机在宽屏/窄屏都包含目标、爆点及可见碎片余量；切回全景仍显示完整原设计。
4. 观察碎片仅改屋顶/烟尘/剖视，不能清除计算结果或改变载荷。
5. 复用旧结果时保持原配置与全部帧，不把回放当成新求解。
