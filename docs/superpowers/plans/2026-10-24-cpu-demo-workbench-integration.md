# 用五类轻量场景替换 CPU 默认模拟入口

目标：用户要求将已实现的五类独立场景覆盖原CPU模拟，适配现有布局与颜色。直接使用原 `/cpu-blast` 路由，复用轻量Worker与几何；原工程页面、后端、运行时和结果保留。

设计选择：独立CPU外壳共享现有演示控制器，加载工作台导航与浅色主题；左参数/右视图区，下方时间轴与指标曲线，小屏调整为视图优先的单列。页内下拉选择五场景，URL稳定、草稿按场景隔离；旧source参数兼容，旧工程run_id不当成新结果。新结果缓存到独立IndexedDB，与旧工程记录隔离。颜色统一白/浅灰/青，爆源及破坏语义色保留。原演示URL继续可用。

执行约束：保留全部已有修改和证据，不创建工作树、不提交、不清理旧结果；不运行整栋自重、13单元、原生TNT、全量及重型案例，不启动会修改历史任务状态的旧WebAppServer。只做新页面、静态路由、缓存及相关演示专项；可见Edge检查桌面显示。
