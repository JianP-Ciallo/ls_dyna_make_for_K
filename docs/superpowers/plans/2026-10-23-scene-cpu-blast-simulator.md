# 五类建筑场景 CPU 爆炸模拟器实施清单

依据：[已确认的产品设计](../specs/2026-10-22-scene-cpu-blast-simulator-design.md)。2026-10-23 用户授权开始实施。沿用当前工作区，不提交、合并或清理既有修改。

## 全局约束

- 主入口是建筑场景与单个 TNT，单柱/单板留在原开发验证页面。
- 只进行专项单元、微型力学夹具、模拟任务接口与浏览器交互检查。本次不启动五类真实建筑求解、不恢复旧收敛矩阵、不进行全量/重型测试。
- 几何、承重、质量、荷载、损伤、失败记录和结果均有独立身份；旧压力倍率不能转换成 TNT 当量。
- 第一版为研究用刚体弹簧宏单元：分布连接传递轴力、剪力与力矩，断裂能控制拉伸软化，钢筋独立屈服；失效保留质量/重力。接触先限地面，构件相互碰撞尚未验证时在首次相交处停止并给出部分结果，不继续穿透来冒充倒塌。
- 经验荷载先限定单个室外贴地 TNT、开阔场地，采用有许可的 Swisdak 简化 Kingery 地面爆炸参数；不声称支持高空爆炸、室内或复杂城市传播。城市结果必须标明不含遮挡、绕射与多重反射。
- 实际整栋速度与数值适用范围待获准试算；不能把本次微型验证写成整栋验收。

## Task 1：合同、五类来源与轻量准备

先写 `tests/test_scene_blast_sources.py`，检查输入验证、确定身份、质量/支持检查、城市变换、固定三层柱板政策；再在 `architecture/scene_blast/` 实现独立合同与来源适配。沿用已有粗壳构建器及固定建筑密封元数据/规整参考几何，预算超限明确拒绝，不自动细化或生成 ALE。

输出接口：不可变 `scene-blast-input@1`、`scene-blast-model@1`；稳定构件 ID、刚体几何、连接、受载面、质量账本、来源/假设、预算。

## Task 2：荷载与非线性宏单元

先写 `tests/test_scene_blast_physics.py`：KB 数值、量纲与缩尺、压力冲量积分、刚体客观性、轴向/弯曲连接、拉伸软化耗能与不可逆性、钢筋屈服、失效后质量与自由落体、地面接触、初始重力残差、稳定步长与超时。实现 SI 单位内核与实时极值提取。仅运行微型夹具，不运行真实模型。

输出接口：`scene-blast-result@1`，带输入/模型/方法身份、真实帧、构件曲线、峰值、事件、限制与终止原因。刚度奇异、重力不平衡或不支持接触不得发布 completed。

## Task 3：任务与 HTTP

先写 `tests/test_scene_blast_service.py`，用假运行器覆盖单任务、幂等、冻结输入、取消、失败、超时、删除/恢复与历史回放。实现 `/api/cpu-blast/` 独立接口和受控子进程；GET 不计算；仅明确 Start 创建任务；结果校验哈希；不接收任意本地文件路径。

## Task 4：场景工作台与导航

新增 `/cpu-blast` 页面，复用统一浅色/青色主题。左侧五类模型/TNT/设置/开始停止，中央原几何与可拖动爆源，底部回放，右侧构件结果/曲线。编辑输入立即解绑旧结果，旧任务不会覆盖新场景。草稿按项目/模型版本隔离，原 CPU 地址和历史保留；顶部 CPU 链接指向新场景。保存/加载场景快照、历史删除恢复、曲线导出。

## Task 5：专项验证与独立审查

运行上述指定测试文件与无计算浏览器夹具；检查五类预览和导航草稿。必要时复用一名独立审查者，仅审本次差异。修复阻塞问题，保存证据。最后报告具体已实现内容、真实场景尚未试算/验收的边界，以及下一次真实试算的建议范围和耗时，不自动运行。
