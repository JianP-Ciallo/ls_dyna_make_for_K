# Phase 11.9 Developer Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a complete developer/reviewer distribution zip with an accurate Chinese README for the current Web App, MCP, LS-PrePost, LS-Run handoff, and verification workflow.

**Architecture:** Keep the existing packaging boundary in `scripts/pack.ps1`: copy reviewed source directories into an isolated staging directory, scan the staged text for local paths, create a SHA256 manifest, and compress to a timestamped zip. Treat the root README as the quick operational entry and `README.zh-CN.md` as the detailed developer/MCP reference; protect their key claims with a lightweight regression test.

**Tech Stack:** Python 3.10+, `unittest`, PowerShell, `Compress-Archive`, Markdown, Windows batch startup.

## Global Constraints

- Package label is exactly `phase11.9-lsrun-handoff-dev`.
- Keep source, tests, examples, scripts, templates, materials, Web App files, and public documentation.
- Exclude `.git`, `dist`, `workspace`, `projects`, `generated_configs`, caches, local paths, local executable configuration, generated models, patent drafts, and internal design artifacts.
- Describe LS-Run as a validated local handoff that opens LS-Run; do not claim automatic job population, solve submission, monitoring, or result interpretation.
- Do not create a git commit unless the user explicitly requests one.
