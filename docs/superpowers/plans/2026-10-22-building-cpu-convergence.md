# 三层柱板 CPU 网格与时间步长收敛验证计划

## Global Constraints

- 承重体系、设计柱恢复及重叠体积扣除、原始筋位/层位、材料、基础、附属质量/传力规则保持不变。无新增梁、刚性楼盖、经验空气爆炸或非线性。
- 只对 `F0.west.front.0` 的 south 面施压，有效面积9.0666m²；0→1ms达10kPa→10ms卸载→150ms结束，零阻尼。五例均从零初态重新建模。
- 最多五次真实整栋动力任务；不含自动重试、冷/热重复、第二墙面、额外荷载、全量、原重型组或LS-DYNA。
- 最多一个计算worker，串行运行；任何任务超时、内存超限、原生失败、身份或产物核验失败均停止后续任务，保留已完成与失败证据。
- 未达到数值门槛不接入网页整栋功能，不删除/平滑钢筋峰值、不改时窗或阈值来取得通过。
- 保留所有原文件、已有修改和历史证据；不清理、提交、合并或另建工作树。

## Review Focus

1. 只降低目标大格尺寸、却不细分峰值附近小格会制造虚假的峰值收敛：细分每个现有壳格及每个柱段，检查嵌套关系和热点格尺寸。
2. 源实体/受压面的积分点跨越新的形函数分区时，仅总质量/合力守恒仍可能局部分配不准：先分片积分，检查逐层质量/局部虚功，不用总量掩盖误差。
3. mesh/source指纹本来随离散改变：以物理定义签名、全部原K哈希及相同代码/运行环境核验同一问题，禁止仅因source指纹不同拒绝合法网格，或仅因总质量相同接受不同模型。
4. 0.025ms需6000步/6001个原始时间点；不能静默丢弃真实峰值或超过旧样本/产物上限后误报成功。
5. 柱板点连接附近可能存在局部应力奇异性；保留原始钢筋极值及位置，不用云图均值或区域平均替代原始峰值门槛。

## 验收规则

**这些是本项目拟采用的数值门槛，不是行业强制标准，也不表示相对实测误差≤2%。**

### 同一物理问题及积分前提

- 每例验证原K、封存语义、规整政策、材料、筋位、边界和物理荷载签名相同；模板、输入、代码、环境和产物哈希齐全。每例输入哈希不同且可复算；五例代码身份完全一致。
- 总物理质量、一阶矩和二阶矩相对误差≤1e−9；压力面积/合力/力矩/冲量相符。固定质量与动力质量是离散分配结果，允许细化时改变，但须报告及核对，不能强行改数使其相等。
- 板/板筋归本层、柱筋归柱链、墙上下真实净跨反力及偏心规则不变。跨求解格的源实体/面先切分积分，局部分配用小夹具独立对照。
- 七类柱截面EA及轴弯耦合/弯曲刚度、板层ABD先与同一几何的独立积分对照，目标≤0.5%；这属于截面小专项，不新增整栋工况。若需提高截面积分精度，五例统一使用修正后的同一设置后再运行。

### 空间收敛

M0→M1→M2保持dt=0.1ms，计算相邻两档变化，末两档M1/M2下列关键量≤2%：

1. 全楼及各楼层节点位移幅值峰值。
2. 全楼钢筋原始积分点绝对峰值、最大拉/最小压峰值；柱纵筋与板上下X/Y层分别统计，保留组件/采样点/位置/时间。
3. 共同物理监测点位移向量曲线、各钢筋组的原始极值时程。比较完整0–150ms，不只取前10ms。
4. 原630个共同节点在0、5、…、150ms的位移场；另保存两类真实全局峰值帧，不能用抽稀动画代替比较数据。

标量/曲线统一以较细解为参照：`|Qfine−Qcoarse|/|Qfine|`；曲线用共同时间点最大差除以该较细曲线全时窗最大幅值。位移向量用二范数。近零量按预先固定的绝对容差（位移1e−12m，应力0.02Pa）处理并单列，不用修改分母隐藏误差。

三档还须呈稳定趋势：相邻误差e12≤e01，或两者均≤0.1%视为误差平台；明显振荡、热点跳跃或误差反增单列为未验证，不凭一对数值小于2%宣告全部通过。原始峰值持续升高时，检查点连接/局部奇异性；必要时另提有物理尺度的接头模型方案，不能先删峰开放应力功能。

### 时间收敛与解耦

- 在完全相同的M2网格上比较0.1→0.05→0.025ms；**两次减半**的上述峰值/共同曲线变化均≤2%，且最后变化不大于前次，或两者均≤0.1%。
- 同一主导热点的峰值时刻差≤`max(2%×较细峰时, 较粗dt)`；多个近等峰造成主导位置/时刻切换时标记不确定，保留完整时程，不用全局峰时跨地点硬比较。
- 若0.1ms在M2不满足门槛，即便0.05/0.025ms相符，也不宣布固定0.1ms得到的空间比较已验收。该情形只报告时间结果，另列较小dt的M0/M1补测范围和耗时，重新取得当次同意；不自动追加第六例。
- 不在不足一个周期的150ms屋面曲线上声称周期已收敛；本次结论只覆盖固定的150ms窗口。

### 完整性与数值诊断

- 每例完整150ms、预定步数、有限值、真实峰值帧、源文件及产物校验均通过；原生应力核对仍保留，不以显示均值/新平滑值代替。
- 无阻尼卸载后11–150ms非零机械能的相对范围≤0.5%；近零能量单列绝对量。能量稳定不能代替空间或时间门槛。
- 完整动力平衡核对外力、内力和惯性；不能把有惯性的瞬态基础反力直接与外力要求静力相等。
- 每例未超过单例/批次时限和4GiB进程RSS；超时、失败、取消、未运行分别列示。计算性能与前端加载/首帧性能分开，当前不宣称网页180s预算已通过。

## 资料与自检

本计划参考连续细化、保持同一问题、比较多档解的通用思路；没有直接把CFD的GCI当作本结构模型的强制标准或预设观测阶。[NASA 网格收敛说明](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)；[COMSOL 网格细化说明](https://www.comsol.com/support/knowledgebase/1261)提醒尖角导数量可能局部不收敛；[OpenSees Newmark 文档](https://openseesdocumentation.readthedocs.io/en/latest/user/manual/analysis/integrator/Newmark.html)对应本模型gamma=0.5、beta=0.25，算法阶次不能代替实际dt检查。
